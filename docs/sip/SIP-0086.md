## Obiettivo

Connettere il backend PHP Yii2 ai contratti su Besu tramite un layer Bridge leggero,
senza dipendenze heavy (nessun Node.js nel container PHP).

## Approccio: JSON-RPC diretto via cURL

Besu espone un endpoint JSON-RPC standard. Il bridge PHP chiama direttamente
`eth_call` e `eth_sendRawTransaction` via cURL, firmando localmente le tx.

```
PHP ──cURL──► Besu JSON-RPC (http://besu:8545)
                 │
                 ▼
          GameEconomy.sol / GoldManagerCoin.sol
```

## BridgeService.php

```php
namespace app\components;

class BridgeService
{
    public static function getBalance(int $teamId): string;         // GMC balance
    public static function payWage(int $teamId, int $playerId, string $amount): string;   // tx hash
    public static function recordTransfer(int $sellerId, int $buyerId, int $playerId, string $fee): string;
    public static function recordSponsor(int $teamId, string $amount): string;
    public static function getTxHistory(int $teamId, int $limit = 50): array;
}
```

Ogni chiamata che scrive on-chain firma la transazione con la chiave privata del
server wallet (custodial) conservata in `GM_BESU_SERVER_PRIVATE_KEY`.

## Firma locale

- Libreria PHP pura: `kornrunner/keccak` + `simplito/elliptic-php` per ECDSA secp256k1.
- Nessun Node.js, nessun web3.php pesante.
- Alternativa: microservizio Go separato che firma e invia (più sicuro per la chiave).

## Configurazione

| Env var                    | Descrizione                          | Default            |
|----------------------------|--------------------------------------|--------------------|
| `GM_BESU_RPC_URL`          | URL JSON-RPC Besu                    | `http://besu:8545` |
| `GM_BESU_CHAIN_ID`         | Chain ID rete privata                | `1337`             |
| `GM_BESU_SERVER_WALLET`    | Indirizzo wallet server              | —                  |
| `GM_BESU_SERVER_PRIVATE_KEY` | Chiave privata server (custodial)  | —                  |
| `GM_BESU_GAME_ECONOMY_ADDR`| Indirizzo contratto `GameEconomy`    | —                  |
| `GM_BESU_GMC_ADDR`         | Indirizzo contratto `GoldManagerCoin`| —                  |
| `GM_BESU_ENABLED`          | Abilita integrazione on-chain        | `0`                |

`GM_BESU_ENABLED=0` disabilita silenziosamente tutte le chiamate on-chain: le
operazioni economiche continuano a funzionare solo su DB (backwards compatible).

## Fallback

Se Besu non è raggiungibile:
- Log warning in Yii2.
- Operazione completata solo su DB.
- Flag `blockchain_pending=1` sulla riga (es. `transfer.blockchain_pending`).
- Cron `economy/sync-blockchain-pending` ripropone le tx in coda.

## Acceptance Criteria

- [ ] `BridgeService::getBalance()` ritorna saldo GMC reale da Besu.
- [ ] `BridgeService::payWage()` scrive tx on-chain e ritorna hash.
- [ ] `GM_BESU_ENABLED=0` bypassa silenziosamente ogni chiamata RPC.
- [ ] Fallback: operazioni DB completate anche se Besu è down.
- [ ] Cron `sync-blockchain-pending` riprova tx fallite.
