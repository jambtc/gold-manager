# SIP-0032 — Formation View Enhancement: Skill Bars, Position Hints & Player Card

| Field   | Value                 |
|---------|-----------------------|
| Status  | Implemented ✅             |
| Author  | Gold Manager Dev Team |
| Created | 2026-05-18            |

## Summary

Enhance the formation view player list to show:
1. **Forma e Freschezza as progress bars** (%, coloured) instead of raw numbers
2. **Stat-based position suggestion** — highlight which zone is best for the player based on their strongest skills
3. **Expanded player card** in the list with all relevant stats visible at a glance
4. **Special skill badges** (SVG icons, see [[SIP-0033]]) on each player card

---

## Part A — Forma / Freschezza / Condizione as Bars

### Current state
Values shown as `F100% Fr100%` plain text.

### Target
Each stat rendered as a coloured progress bar:

```
Forma     ████████░░  84%   (green ≥80, gold 55–79, red <55)
Freschezza████████░░  78%   (blue gradient)
Condizione███████░░░  70%   (orange gradient)
```

### Implementation
In `views/formation/view.php`, replace the stat text spans with:

```php
$statBar = function(string $label, int $val, string $color): string {
    return '<div style="margin-bottom:.15rem">'
        . '<div style="display:flex;justify-content:space-between;font-size:.6rem;color:var(--text-secondary)">'
        . '<span>' . $label . '</span><span>' . $val . '%</span></div>'
        . '<div style="background:rgba(255,255,255,.07);border-radius:2px;height:4px">'
        . '<div style="width:' . $val . '%;height:100%;background:' . $color . ';border-radius:2px"></div>'
        . '</div></div>';
};
```

Colours:
- Forma: `var(--accent-green)` ≥80, `var(--gold)` 55–79, `var(--accent-red)` <55
- Freschezza: `var(--accent-blue)`
- Condizione: `#f97316`

## Part B — Position Suggestion Based on Stats

### Logic
After the player's stat bars, show a **"Zona suggerita"** indicator derived from their stat profile:

| Dominant stat combination | Suggested role | Icon |
|--------------------------|---------------|------|
| `skill_po` highest       | Portiere       | 🥅 |
| `skill_df` + `skill_tc` high | Difensore  | 🛡️ |
| `skill_cn` + `skill_pa` high, `skill_rg` high | Mezzala/Regia | ⚙️ |
| `skill_cr` high + lateral player | Ala (fascia) | ⚡ |
| `skill_tr` + `skill_rg` high | Attaccante | ⚽ |
| `skill_tr` + lateral, `skill_cr` high | Seconda punta | 🎯 |

Rule engine (PHP, pure stat comparison):
```php
function suggestZone(Player $p): string {
    if ($p->skill_po > 70) return 'Portiere';
    if ($p->skill_df >= $p->skill_tr && $p->skill_tc >= 50) return 'Difensore';
    if ($p->skill_rg >= 60 && $p->skill_pa >= 55) return 'Regia';
    if ($p->skill_cr >= 60) return 'Ala (fascia)';
    if ($p->skill_tr >= 60) return 'Attaccante';
    return 'Jolly';
}
```

This hint is shown as a small coloured pill under the stat bars in the player list.
