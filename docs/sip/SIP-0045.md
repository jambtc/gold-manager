## Part B — Season Totals View

No new table needed. Season totals are computed by aggregating `player_stat`:

```sql
-- Season scorers
SELECT p.name, p.position, t.name AS team,
       SUM(ps.goals)         AS gol,
       SUM(ps.assists)       AS assist,
       SUM(ps.yellow_cards)  AS gialli,
       SUM(ps.red_cards)     AS rossi,
       COUNT(ps.fixture_id)  AS partite
FROM player_stat ps
JOIN player p ON p.id = ps.player_id
JOIN team   t ON t.id = ps.team_id
JOIN fixture f ON f.id = ps.fixture_id
JOIN competition c ON c.id = f.competition_id
WHERE c.season = :season AND c.type != 'friendly'
GROUP BY ps.player_id
ORDER BY gol DESC, assist DESC;
```

Add a Yii2 `StatsController::actionScorers()` and view at `/stats/scorers`.

## Part C — Team Stats per Match

Extend the `standing` table with additional season-aggregate columns:

```sql
ALTER TABLE standing
  ADD COLUMN penalties_for      TINYINT NOT NULL DEFAULT 0,
  ADD COLUMN penalties_against  TINYINT NOT NULL DEFAULT 0,
  ADD COLUMN clean_sheets       TINYINT NOT NULL DEFAULT 0,
  ADD COLUMN biggest_win_home   TINYINT NOT NULL DEFAULT 0,
  ADD COLUMN biggest_win_away   TINYINT NOT NULL DEFAULT 0;
```

These are updated in `MatchEngine::updateStanding()` at the end of each match.

## Legacy Reference

From `gu-classic/form_giocatori_esporta.php` — player fields:
```
part, reti, gialli, rossi        ← current season
part2, reti2, gialli2, rossi2    ← previous season (keep for rollover)
```

From `oldGM/classifica.php`:
```sql
SELECT * FROM z_marcatori WHERE serie='$serie' ORDER BY gol DESC
```
`z_marcatori` was a denormalized table rebuilt after each match. In v2 we compute
it dynamically from `player_stat` — no separate table needed.
