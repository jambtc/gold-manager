## Summary

Players accumulate yellow and red cards during competitive matches.
Yellow cards lead to suspension after threshold. Red cards cause immediate
match ejection (10-men team) and a mandatory 1-match ban.

Restored from `oldGM/data_giocatori_vendi.php`: columns `gialli`, `rossi`,
`gialli2`, `rossi2` (current and previous season tallies).

## Card Generation During Match

### Yellow Card (`yellow_card` event)

Generated in `MatchEngine::resolveTick()` after a tackle/duel event:

```php
$yellowChance = 0.015; // 1.5% per tackle tick

// Character modifiers (SIP-0037)
$charMod = match(strtolower($character)) {
    'grintoso'   => 1.30,  // +30% yellow chance
    'irrequieto' => 1.50,  // +50% yellow chance (more red cards too)
    'corretto'   => 0.50,  // −50% yellow chance
    'diligente'  => 0.80,  // −20%
    default      => 1.00,
};

// Staff: vice-allenatore reduces card risk via discipline training
$staffMod = 1 - ($assistant_efficiency / 100 * 0.10);

$prob = $yellowChance * $charMod * $staffMod;

if (mt_rand(1, 10000) <= (int)($prob * 10000)) {
    $player->yellow_cards++;
    $player->save(false);
    $event = 'yellow_card';
    
    // Check suspension threshold
    if ($player->yellow_cards >= 5) {
        $player->suspended_matches = 2; // 5th yellow = 2-match ban
        $player->yellow_cards = 0;      // reset after suspension
    } elseif ($player->yellow_cards % 3 === 0) {
        $player->suspended_matches = 1; // every 3rd yellow = 1-match ban
    }
}
```

### Red Card (`red_card` event)

Rare event — direct red or second yellow:

```php
// Direct red: ~0.1% per foul
$redChance = 0.001 * $charMod;

if (mt_rand(1, 100000) <= (int)($redChance * 100000)) {
    $player->red_cards++;
    $player->suspended_matches += 1;
    $player->save(false);
    $event = 'red_card';
    
    // Eject player: team totals reduced
    $state->setEjected($side, $player->id);
}

// Second yellow in same match → red
if ($playerYellowsThisMatch[$player->id] >= 2) {
    // same logic as red card above
}
```

## 10-Men Effect (Post-Ejection)

When a player is sent off, the team department totals are penalized for the
remaining ticks of the match:

```php
// In computeTeamTotals, after calculating totals:
if ($state->isEjected($side)) {
    // Remove one outfield player's contribution (~9%)
    $penalty = 0.91;
    foreach (['df','cn','rg','pa','cr','tc','tr','at_L','at_C','at_R'] as $k) {
        $totals[$k] = (int)($totals[$k] * $penalty);
    }
}
```

The ejection is stored in `match_state.pending_home_actions` or a new field:
`match_state.home_ejected` / `match_state.away_ejected` (boolean).

## Suspension Logic

`EconomyController::checkSuspensions()` runs before each fixture week:

```php
foreach ($players as $player) {
    if ($player->suspended_matches > 0) {
        // Block from formation (same as injury)
        // After the fixture: suspended_matches--
    }
}
```

Players with `suspended_matches > 0`:
- Cannot be assigned to formation (FormationController validates)
- Formation view shows 🟨 badge and blocks dragging
- Suspended on next competitive fixture only (not friendlies)
