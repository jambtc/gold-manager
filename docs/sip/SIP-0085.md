# SIP-0085 — Wallet Manager UI (GMC)

| Campo   | Valore                                         |
|---------|------------------------------------------------|
| Status  | Proposed                                       |
| Autore  | Gold Manager Dev Team                          |
| Data    | 2026-06-02                                     |
| Dipende | SIP-0082 (token economy), SIP-0086 (Bridge)    |

## Obiettivo

Fornire al manager una sezione **Portafoglio** in-game dove vedere il saldo GMC,
la cronologia delle transazioni on-chain e (opzionalmente) collegare un wallet MetaMask.

## Sezioni UI

### 1. Dashboard portafoglio (`/wallet`)

| Elemento              | Descrizione                                          |
|-----------------------|------------------------------------------------------|
| Saldo GMC             | Aggiornato in tempo reale via bridge PHP             |
| Indirizzo wallet      | Generato lato server o collegato via MetaMask        |
| Variazione 24h        | Delta GMC rispetto al giorno precedente              |

### 2. Cronologia transazioni

Tabella paginata:

| Colonna    | Fonte                        |
|------------|------------------------------|
| Data/ora   | `block.timestamp` on-chain   |
| Tipo       | `GameEvent.category`         |
| Controparte | Manager o Sistema           |
| Importo    | GMC (positivo/negativo)      |
| Tx hash    | Link al Besu explorer        |

### 3. Collegamento MetaMask (opzionale, fase 2)

- Pulsante "Collega wallet esterno".
- Firma messaggio EIP-191 per verifica ownership.
- Una volta collegato, le transazioni vengono firmate dal wallet del manager.

## Architettura

```
Browser ──fetch──► WalletController (PHP)
                      │
                      ▼
                 BridgeService::getBalance(teamId)
                      │
                      ▼
                 Besu JSON-RPC / GameEconomy.sol
```

`WalletController` (nuovo controller Yii2):

- `actionIndex()` — dashboard con saldo e ultime 20 tx.
- `actionHistory()` — cronologia paginata.
- `actionConnect()` — verifica firma MetaMask (fase 2).

## Acceptance Criteria

- [ ] `/wallet` mostra saldo GMC corrente del manager.
- [ ] Cronologia mostra ultime 50 transazioni con tipo e importo.
- [ ] Saldo si aggiorna entro 30s da un'operazione in-game.
- [ ] Link tx hash apre il Besu explorer.
- [ ] UI funziona anche se Besu è temporaneamente irraggiungibile (fallback: saldo cached).
