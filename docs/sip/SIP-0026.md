# SIP-0026 — AI Match Commentary (Claude Haiku)

| Field   | Value                     |
|---------|---------------------------|
| Status  | Accepted (Implemented)     |
| Author  | Gold Manager Dev Team      |
| Created | 2026-05-16                |

## Summary

Integrate Claude Haiku into the match engine to generate Italian-language live
commentary for every significant match event. Commentary is generated at tick
time, stored in `match_event.commentary`, and displayed in the live view with
a typewriter animation.

---

## Problem

The live match view exposes raw engine output — event types, scores, player
IDs. Functional, but not immersive. A football manager game lives or dies on
the emotional engagement of its match experience. Programmatic templates
produce repetitive, generic phrases. An LLM reacts to the actual game state
(score, minute, player names, character traits) and produces varied,
emotionally charged telecronache — something a template can never achieve.

---

## Design Decisions

### Pre-generated vs real-time SSE

| Concern | Pre-generated | Real-time SSE |
|---------|--------------|---------------|
| Works in background (no viewer) | ✅ | ❌ |
| One API call per event, not per viewer | ✅ | ❌ |
| Zero latency in live view | ✅ | ❌ (~500ms) |
| Streaming "live" feel | simulated (JS) | native |
| Works when API is down | ✅ fallback | ❌ |

Pre-generation wins on every operational axis. The "live" feel is reproduced
client-side with a JS typewriter animation.

### Model choice: Claude Haiku

- Fastest response (~300ms per event)
- Cheapest: ~$0.00006 per call
- Sufficient quality for 2-3 sentence commentary
- Native Italian output without fine-tuning

### 2. CommentaryGenerator Component

**Location:** `components/CommentaryGenerator.php`

```php
class CommentaryGenerator extends Component
{
    public string $model   = 'claude-haiku-4-5-20251001';
    public int    $maxTokens = 120;
    public bool   $enabled = true; // false in tests / when API key missing

    public function generate(MatchEvent $event, Fixture $fixture): ?string
```

**System prompt (cached):**

```
Sei un telecronista italiano di calcio entusiasta e appassionato.
Il tuo compito è generare esattamente 2 frasi di telecronaca vivace.

Regole assolute:
- Solo italiano.
- Stile enfatico, presente indicativo.
- Varia esclamazioni e costruzioni sintattiche ad ogni evento.
- Niente emoji. Niente hashtag. Niente liste.
- Esattamente 2 frasi. Punto finale obbligatorio.
```

**User message (dynamic, per event):**

```
Partita: {homeTeam} vs {awayTeam}
Minuto: {minute}'  |  Risultato: {homeScore}-{awayScore}
Evento: {eventType}
Squadra: {side}
{playerLine?}
{detailLine?}
```

**Events that receive commentary:**

| Type | Narrative weight |
|------|-----------------|
| `kickoff` | Intro breve |
| `goal` | Massima enfasi, include nuovo punteggio |
| `gk_save` | Eroismo del portiere |
| `near_miss` | Tensione, opportunità mancata |
| `substitution` | Commento tattico |
| `half_time` | Tono di bilancio |
| `second_half_start` | Rientro in campo |
| `full_time` | Narrativa del risultato finale |

`midfield_win`, `attack_attempt`, `shot_on_goal` — **nessuna commentary**
(troppo frequenti, basso valore narrativo).

### 3. Integrazione con MatchEngine

Dopo che ogni `MatchEvent` viene salvato:

```php
// MatchEngine, dopo $event->save()
if ($this->commentaryGenerator->shouldComment($event->type)) {
    $text = $this->commentaryGenerator->generate($event, $fixture);
    if ($text !== null) {
        $event->commentary = $text;
        $event->save(false);
    }
}
```

`CommentaryGenerator` è iniettato via DI container (`config/web.php` +
`config/console.php`):

```php
'commentaryGenerator' => [
    'class'   => \app\components\CommentaryGenerator::class,
    'enabled' => (bool) getenv('COMMENTARY_ENABLED'),
],
```

---

### 4. Prompt Caching

Il system prompt (persona + regole) è invariante per tutti gli eventi.
Va contrassegnato con `cache_control: {"type": "ephemeral"}` usando
l'Anthropic Messages API. Il blocco dinamico (dati evento) resta fuori cache.

Risparmio stimato: **−90% sui token di input del system prompt**.

```php
$messages = [
    [
        'role'    => 'user',
        'content' => [
            [
                'type' => 'text',
                'text' => $systemPrompt,
                'cache_control' => ['type' => 'ephemeral'],
            ],
            [
                'type' => 'text',
                'text' => $eventBlock,
            ],
        ],
    ],
];
```

---

### 5. Live View

Il endpoint di polling `/api/fixture/{id}/events?since={minute}` aggiunge
il campo `commentary` al JSON di risposta:

```json
{
  "minute": 67,
  "type": "goal",
  "team_side": "home",
  "commentary": "GOOOOOL! Ferretti si coordina di destro e trafigge il portiere in uscita! Il tabellone dice 2-1 e il pubblico non ci crede ancora!"
}
```

Il frontend applica un **typewriter effect** (~30ms/char):

```js
function typewrite(el, text) {
    let i = 0;
    el.textContent = '';
    const id = setInterval(() => {
        el.textContent += text[i++];
        if (i >= text.length) clearInterval(id);
    }, 28);
}
```

Fallback quando `commentary === null`: stringa localizzata predefinita
(es. `"67' — Tiro in porta, para il portiere!"`).

---

### 6. Configurazione

```env
ANTHROPIC_API_KEY=sk-ant-...
COMMENTARY_ENABLED=true
```

Se `ANTHROPIC_API_KEY` è assente, `CommentaryGenerator` logga un warning
e ritorna `null`. Il motore di gioco continua senza errori.

---

### 7. Estensioni future

- **Match report**: a fine partita, un secondo call genera un riassunto
  narrativo della partita intera (500-800 token, Sonnet).
- **Personalizzazione**: il prompt può includere lo storico recente della
  squadra (forma, infortuni) per commenti contestuali.
- **Multilingua**: il prompt può essere adattato in base alla lingua
  dell'utente (IT/EN/FR) senza cambiare l'engine.

## Acceptance Criteria

- [ ] `match_event.commentary` column esiste (TEXT NULL).
- [ ] `CommentaryGenerator::generate()` chiama Claude Haiku per i tipi evento elencati in §2.
- [ ] Commentary salvata in `match_event.commentary` al momento del tick.
- [ ] Se `COMMENTARY_ENABLED=false` o la chiamata API fallisce, l'engine non genera errori.
- [ ] Live view mostra commentary con typewriter animation.
- [ ] Live view fallback a stringa template quando `commentary` è NULL.
- [ ] Prompt caching abilitato sul system prompt block.
- [ ] Unit test: `CommentaryGenerator` con `enabled=false` ritorna null senza HTTP calls.
- [ ] Integration test: simulazione completa produce commentary non-null sugli eventi goal.
