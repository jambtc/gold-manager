## Obiettivo

Introdurre un valore discreto di **impegno/strength mentale-fisico squadra**
modificabile:

- in `formation/view` o pannello tattica pre-partita;
- durante `fixture/live` tramite comando immediato al match engine.

Valori ammessi:

| Valore | Significato | Uso |
|--------|-------------|-----|
| 0      | Risparmio totale | Amichevoli leggere, finale gia deciso |
| 25     | Basso impegno | Gestione energia |
| 50     | Standard | Default |
| 100    | Massimo impegno | Pressione finale, recupero risultato |

Default: `50`.

---

## Regole gameplay

L'impegno modifica il rendimento istantaneo e il consumo fisico.

### Moltiplicatore rendimento

```
0   -> performance x 0.88
25  -> performance x 0.95
50  -> performance x 1.00
100 -> performance x 1.08
```

Il bonus deve pesare sul match engine, non sull'OVR statico del giocatore.

### Consumo freschezza

```
0   -> freshness cost x 0.55
25  -> freshness cost x 0.80
50  -> freshness cost x 1.00
100 -> freshness cost x 1.55
```

### Rischio infortuni

```
0   -> injury risk x 0.70
25  -> injury risk x 0.90
50  -> injury risk x 1.00
100 -> injury risk x 1.45
```

Il rischio infortuni resta disattivato in amichevole se la regola corrente lo prevede.

---

## Persistenza

### `formation`

Aggiungere colonna:

```sql
effort_level TINYINT UNSIGNED NOT NULL DEFAULT 50
```

Validazione: solo `0, 25, 50, 100`.

### `match_state`

Aggiungere snapshot live:

```sql
home_effort_level TINYINT UNSIGNED NOT NULL DEFAULT 50,
away_effort_level TINYINT UNSIGNED NOT NULL DEFAULT 50
```

All'avvio partita:

- home prende `formation.effort_level` della formazione snapshot;
- away idem;
- CPU usa default `50` se non configurato.

---

## UI

### Pre-partita / tattica

In `formation/view` aggiungere controllo segmentato:

```
[0] [25] [50] [100]
```

Label: `Impegno`.

### Live

In `fixture/live` aggiungere stesso controllo nel pannello live setup.

Click manager:

```
POST /live-action/effort
fixtureId
effort_level
```

Il comando aggiorna subito `match_state.{side}_effort_level` e registra evento:

```json
{
  "type": "effort_change",
  "team_side": "home",
  "effort_level": 100,
  "description": "Jammin Calcio alza l'impegno al massimo."
}
```

## Motore partita

### PHP engine

Applicare effort a:

- `computeTeamTotals()` / reparto squadra;
- consumo freschezza post-match;
- rischio infortunio, se attivo.

### Go worker

Applicare stesse formule a:

- soglie gol/azioni;
- `resolveGoInjury()`;
- future logiche di fatigue live.

Regola progetto: PHP sim e Go worker devono restare allineati.
