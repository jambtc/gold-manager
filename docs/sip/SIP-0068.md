## Quadranti canonici (10)

```
gk
def_l def_c def_r
mid_l mid_c mid_r
att_l att_c att_r
```

Mapping zona -> quadrante tramite `PitchZoneHelper::coords(int $zone)`:
- GK (`64` display o `10` engine) -> `gk`
- `row 2..4` -> `def_*`
- `row 5..7` -> `mid_*`
- `row 8..10` -> `att_*`
- `lane 1/2/3` -> `l/c/r`

```sql
CREATE TABLE {{%player_quadrant_exp}} (
    id                  INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    player_id           INT UNSIGNED NOT NULL,
    quadrant            ENUM('gk','def_l','def_c','def_r',

        REFERENCES {{%player}} (id) ON DELETE CASCADE

```

### 2) `player_cell_exp` (micro, 63+1)

```sql
CREATE TABLE {{%player_cell_exp}} (
    id                  INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    player_id           INT UNSIGNED NOT NULL,
    zone                TINYINT UNSIGNED NOT NULL COMMENT '1..64 (64=GK)',
    official_credits    INT UNSIGNED NOT NULL DEFAULT 0,
    friendly_credits    INT UNSIGNED NOT NULL DEFAULT 0,

    CONSTRAINT fk_pce_player FOREIGN KEY (player_id)

```

Crediti sempre interi. Niente `0.5`.

## Accumulo crediti post-match

Fonte minuti: `player_stat.minutes_played`.

Per ogni giocatore con `minutes_played > 0`:
- update quadrante della zona iniziale (`formation_slot.zone`)
- update anche cella specifica (`1..64`)

Regola crediti:
- ufficiale (`competition.type != 'friendly'`):
  - `+2` se `minutes_played >= 60`
  - `+1` se `< 60`
- amichevole:
  - `+1` se `minutes_played >= 45`
  - `+0` se `< 45`

---

## Decay (sempre attivo)

Decay applicato **ogni giorno** nel daily job (`EconomyController`), su tutti i
player con esperienza > 0.

### Decay quadrante (lento)

- se quadrante non usato nelle ultime `Nq=3` partite del player:
  - `official_credits = floor(official_credits * 0.995)`
  - `friendly_credits = floor(friendly_credits * 0.995)`

### Decay cella (piu rapido)

- se cella non usata nelle ultime `Nc=2` partite del player:
  - `official_credits = floor(official_credits * 0.990)`
  - `friendly_credits = floor(friendly_credits * 0.990)`

Clamp minimo: non andare sotto `0`.

Nota: decay sempre on, non configurabile in questa SIP.

---

## Formula bonus

### Raw

```
raw = official_credits * 2 + friendly_credits
```

### Bonus quadrante (cap alto)

```
bonus_q = min(10.0, 10.0 * (1 - exp(-raw_q / 140.0)))
```

### Bonus cella (cap basso)

```
bonus_c = min(3.0, 3.0 * (1 - exp(-raw_c / 90.0)))
```

### Power finale

```
cell_power = clamp(base_overall(zone) + bonus_q + bonus_c, 1, 99)
```

Effetto:
- quadrante guida comportamento principale
- cella rifinisce
