# SIP-0062 — Commentary Fallback Engine + LLM Toggle via ENV

| Field   | Value |
|---------|-------|
| Status  | Accepted (Implemented) |
| Author  | Gold Manager Dev Team |
| Created | 2026-05-20 |

## Summary

Current LLM commentary can produce off-context text.  
This SIP introduces:

1. Global ENV switch to disable LLM enrichment without code edits.
2. Structured fallback commentary engine based on DB templates.
3. Phrase templates by event family, with placeholders for players/teams/context.
4. Weighted random selection + anti-repeat rules.
5. Template-based streaming commentary + suspense/reveal flow (also with LLM OFF).

---

## Goals

- Keep live commentary coherent even with LLM OFF.
- Make text quality controllable by game designers (DB data, no deploy needed).
- Support richer, role-aware text (attacker, defender, goalkeeper, captain, etc.).
- Reuse same fallback source for PHP and Go engine outputs.

---

## ENV Flags

- `GM_LLM_ENABLED=1|0`  
  Master switch for every LLM call.
- `GM_LLM_MATCH_ENRICH_ENABLED=1|0`  
  Match event enrichment only.
- `GM_LLM_PREMATCH_ENABLED=1|0`  
  Pre-match long commentary only.
- `GM_LLM_TIMEOUT_MS=...`  
  Failsafe timeout for LLM requests.
- `GM_COMMENTARY_STREAM_ENABLED=1|0`
  Enables SSE progressive message streaming from templates.
- `GM_SUSPENSE_ENABLED=1|0`
  Enables 2-phase suspense/reveal text flow.
- `GM_SUSPENSE_DELAY_MS=...`
  Delay between suspense and reveal (recommended 2000-3000 ms).
- `GM_TEMPLATE_STREAM_CHUNK_MS=...`
  Delay between streamed chunks/tokens for template text.
- `GM_TEMPLATE_STREAM_MODE=token|clause`
  Stream text as single tokens or short clauses.

If master switch is `0`, system must skip queue/job/API call and use templates directly.

---

## SSE Streaming Contract (Template Engine)

When streaming enabled, server emits:

- `commentary_stream_start`
  - payload: `event_id`, `event_type`, `fixture_id`
- `commentary_stream_token`
  - payload: `event_id`, `token`, `seq`
- `commentary_stream_done`
  - payload: `event_id`, `description`

Compatibility:
- if SSE unavailable, polling receives final `description` only.
- replay mode may render chunked text with simulated timing, or instant full text.

---

## Suspense / Reveal Flow

For eligible actions (`goal`, `gk_save`, `near_miss`, optionally `penalty`, `freekick`):

1. Emit suspense text immediately (`suspense_text`)
   - example: "Rossi prende rincorsa..."
2. After `GM_SUSPENSE_DELAY_MS`, emit reveal
   - `event_reveal` with final outcome text
   - example: "PARATA! Il portiere devia in angolo."

Rules:
- suspense and reveal must refer to same actors (attacker/defender/gk).
- if event finalized before delay path resolves (edge race), reveal still guaranteed once.
- if suspense disabled, emit direct final text.

## New Table: `commentary_template`

Suggested columns:

- `id` PK
- `scope` (`pre_match`, `live`, `half_time`, `full_time`)
- `event_type` (`kickoff`, `goal`, `near_miss`, `gk_save`, `attack_attempt`, `midfield_duel`, `substitution`, `tactic_change`, `yellow_card`, `red_card`, `injury`, `penalty`, `freekick`, `corner`, `offside`, `var`, `extra_time`, etc.)
- `subtype` nullable (`positive`, `negative`, `neutral`, `home_bias`, `away_bias`, ...)
- `priority` int default 100
- `weight` int default 10
- `text` text
- `requires_tokens` json nullable (tokens required by template)
- `min_minute` nullable
- `max_minute` nullable
- `enabled` tinyint(1)
- `created_at`, `updated_at`

Unique index suggestion:
- (`scope`, `event_type`, `subtype`, `id`)

Rule:
- if token missing, template skipped or fallback token map inserted (`"un giocatore"`).

## Selection Rules

- Weighted random by `weight`.
- Exclude templates used in last `N` events of same fixture (`anti-repeat`).
- Prefer subtype consistent with event context:
  - if home scores -> `home_bias`/`positive_home`
  - if save by away GK -> `defensive_away`
- Minute windows:
  - early-match phrases only first 15'
  - late tension phrases from 75'+
- Suspense families have dedicated subtype tags (`suspense_attack`, `suspense_set_piece`, `reveal_goal`, `reveal_save`, ...).

## Engine Integration

### PHP MatchEngine

- `fallbackDescription()` reads `commentary_template` first.
- If no template matched, use hardcoded fallback as last resort.
- Suspense + stream payload populated even when LLM is disabled.

### Go Worker

- Keep existing quick fallback, then call shared template selector endpoint or SQL query.
- Respect `GM_LLM_ENABLED=0` same as PHP.
- Emit same stream/suspense SSE event names for parity with PHP frontend.

### LLM Queue Jobs

- At enqueue and execute time: if ENV says off, short-circuit.

## Acceptance Criteria

- [ ] LLM can be fully disabled via ENV without code changes.
- [ ] No LLM requests when disabled (verified by logs).
- [ ] Templates cover all core match events.
- [ ] Player-aware placeholders rendered in at least 80% of attack/defense events.
- [ ] Anti-repeat working per fixture.
- [ ] PHP and Go both produce coherent fallback text with same template families.
- [ ] Template commentary can stream token/clause updates via SSE.
- [ ] Suspense/reveal works for core shot events with configurable delay.
- [ ] With `GM_LLM_ENABLED=0`, stream+suspense still function end-to-end.
