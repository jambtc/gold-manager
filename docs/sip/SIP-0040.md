# SIP-0040 — Injury System (Infortuni)

| Field   | Value                 |

## Summary

Players can sustain injuries during matches and training with varying severity.
Injured players cannot be selected in formation and may not participate in the
next N matches. The team doctor reduces recovery time.

Restored from `oldGM/team_list.php`: `infortunio` column = weeks remaining.

---

## Severity Levels

| Livello | Settimane assenza | Weeks | Cause tipica |
|---------|-----------------|-------|-------------|
| **Lieve** | 1–2 | 1-2 matches | Contusione, affaticamento muscolare |
| **Medio** | 3–4 | 3-4 matches | Distorsione, strappo muscolare |
| **Grave** | 5–8 | 5-8 matches | Rottura legamenti, frattura |

Stored as `player.injury_weeks` (INT, 0 = healthy).

## Injury Probability During Match

Called at end of each tick in `MatchEngine::checkInjuryRisk()`:

```php
function checkInjuryRisk(Player $player, string $character, int $effort): ?string
{
    // Base probability per tick (90 ticks = 1 match)
    $base = 0.002; // 0.2% per tick = ~18% over 90 min (calibrate down!)
    
    // Age modifier: > 32 → higher risk
    $ageMod = $player->age > 32 ? 1.5 : ($player->age < 22 ? 0.7 : 1.0);
    
    // Condition modifier: low condition → higher risk
    $condMod = 1 + max(0, (60 - $player->condition) / 100);
    
    // Character: corretto → −30%, grintoso/irrequieto → +20%
    $charMod = match(strtolower($character)) {
        'corretto'  => 0.70,
        'grintoso',
        'irrequieto' => 1.20,
        default     => 1.00,
    };
    
    $prob = $base * $ageMod * $condMod * $charMod;
    
    if (mt_rand(1, 10000) <= (int)($prob * 10000)) {
        // Determine severity
        $roll = mt_rand(1, 100);
        if ($roll <= 60) return 'lieve';   // 60% chance
        if ($roll <= 90) return 'medio';   // 30% chance
        return 'grave';                     // 10% chance
    }
    return null;
}
```

**Calibration targets:**
- Per season (~30 matches × 90 ticks = 2700 ticks per player):
  - 15–20% chance of at least one injury per season (realistic football)
  - ~70% lieve, ~25% medio, ~5% grave

## Injury During Training (SIP-0036/0039)

When training intensity is high (alloc total > 80 per week):

```php
$trainingInjuryChance = ($total_load - 80) / 100 * 0.005;
// Max ~0.01% per player per week at maximum load
// Doctor efficiency reduces this
$trainingInjuryChance *= (1 - $doctor_efficiency / 200);
```

## Recovery

`EconomyController::applyWeeklyRecovery()` runs on Monday:

```php
foreach ($injuredPlayers as $player) {
    $reduction = 1; // base: 1 week per week
    $reduction += $doctor_efficiency / 100; // doctor accelerates recovery
    // e.g., doctor efficiency=80 → 1.80 weeks reduction per real week
    
    $player->injury_weeks = max(0, $player->injury_weeks - $reduction);
    if ($player->injury_weeks <= 0) {
        $player->injury_weeks = 0;
        $player->injury_type  = null;
        $player->condition    = 50; // returns at 50% condition
    }
    $player->save(false);
}
```

**Doctor efficiency formula** (from SIP-0035):
- No doctor: base 1 week recovery per week (1:1)
- Doctor efficiency 50: 1.25× speed
- Doctor efficiency 100: 1.5× speed (grave 8 weeks → 5.3 real weeks)

## Match Engine Integration

### Injury occurrence (in `resolveTick`)

After a duel event (tackle, shot), check injury risk on the involved players:
```php
// 20% of duels trigger injury check on the tackled player
if (mt_rand(1, 5) === 1) {
    $injured = $this->checkInjuryRisk($tackledPlayer, $character, $effort);
    if ($injured) {
        $player->injury_weeks = match($injured) { 
            'lieve' => mt_rand(1,2), 'medio' => mt_rand(3,4), 'grave' => mt_rand(5,8)
        };
        $player->injury_type = $injured;
        $player->condition   = 0;
        $player->save(false);
        $events[] = $this->saveEvent($fixture, $min, 'injury', $side, $player->id, [
            'type' => $injured,
            'player_name' => $player->name,
        ]);
    }
}
```

### Injured player cannot start

`FormationController::actionSaveSlot()`: if `$player->injury_weeks > 0`, return error "Giocatore infortunato".
