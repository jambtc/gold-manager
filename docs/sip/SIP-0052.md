# SIP-0052 — LLM Streaming to Browser

| Field   | Value                 |
|---------|-----------------------|
| Status  | Accepted (Implemented) |
| Author  | Gold Manager Dev Team |
| Created | 2026-05-19            |

## Summary

Replace the current async-queue LLM enrichment model with a direct PHP streaming
endpoint. The browser opens an `EventSource` connection per relevant event and
receives Ollama tokens as they are generated, producing a real-time typing effect
without polling delays.

---

## Current Architecture (LlmEnrichJob)

```
SimulateMatchJob → saves fallback text → pushes LlmEnrichJob to queue
Queue worker    → calls Ollama (stream:true, accumulated server-side) → saves full text to DB
Browser         → polls /fixture/get-event-updates every 2s → sees updated description
```

Latency: 5–15 s before text appears. No progressive rendering.

---

## New Architecture (Implemented: Go SSE Token Streaming)

```
Go worker       → writes event with fallback text
Go worker       → calls Ollama stream:true
Go worker       → emits SSE messages llm_stream_start / llm_stream_token / llm_stream_done
Browser         → appends token chunks in real time on existing /stream/{fixtureId}
Go worker       → persists final description in match_event.detail + sends event_update
```

No extra per-event SSE endpoint needed; existing fixture live stream carries token updates.

---

## SSE Message Format

```
data: {"type":"llm_stream_start","id":123}
data: {"type":"llm_stream_token","id":123,"token":"Le squadre "}
data: {"type":"llm_stream_token","id":123,"token":"entrano in campo"}
data: {"type":"llm_stream_done","id":123,"description":"Le squadre entrano in campo..."}
```

## PHP Endpoint Sketch

```php
public function actionStreamLlm(int $eventId): void
{
    $event   = MatchEvent::findOne($eventId);
    $fixture = Fixture::findOne($event->fixture_id);

    // Access check: fixture must belong to a match the user can watch
    // (own team in fixture, or admin)

    header('Content-Type: text/event-stream');
    header('Cache-Control: no-cache');
    header('X-Accel-Buffering: no'); // disable nginx buffering
    ob_implicit_flush(true);

    $prompt  = LlmCommentary::buildPrompt($event->type, $fixture, /* ... */);
    $full    = '';

    LlmCommentary::generateStreaming($prompt, function (string $token) use (&$full): void {
        $full .= $token;
        echo 'data: ' . json_encode(['token' => $token]) . "\n\n";
        flush();
    });

    // Persist full text
    $detail = json_decode($event->detail ?? '{}', true);
    $detail['description'] = $full;
    $event->detail = json_encode($detail, JSON_UNESCAPED_UNICODE);
    $event->save(false);

    echo 'data: ' . json_encode(['done' => true, 'full' => $full]) . "\n\n";
    flush();
}
```

## LlmCommentary Changes

Add `generateStreaming(string $prompt, callable $onToken): void`:

```php
public static function generateStreaming(string $prompt, callable $onToken): void
{
    $payload = json_encode([
        'model'       => self::MODEL,
        'prompt'      => $prompt,
        'stream'      => true,
        'options'     => ['num_predict' => 80, 'temperature' => 0.8],
    ]);

    $handle = curl_init(self::ENDPOINT);
    curl_setopt_array($handle, [
        CURLOPT_POST           => true,
        CURLOPT_POSTFIELDS     => $payload,
        CURLOPT_HTTPHEADER     => ['Content-Type: application/json'],
        CURLOPT_TIMEOUT        => 60,
        CURLOPT_WRITEFUNCTION  => function ($_curl, string $data) use ($onToken): int {
            foreach (explode("\n", $data) as $line) {
                $line = trim($line);
                if (!$line) continue;
                $obj = json_decode($line, true);
                if (isset($obj['response'])) {
                    $onToken($obj['response']);
                }
            }
            return strlen($data);
        },
    ]);
    curl_exec($handle);
    curl_close($handle);
}
```

## Browser Changes (live.php)

When `enqueueEvent` receives a streamable event with no description, instead of
showing a static fallback it opens an EventSource:

```javascript
function streamDescription(eventId, bodyEl) {
    var src = new EventSource(STREAM_LLM_URL + '&eventId=' + eventId);
    var desc = document.createElement('div');
    desc.className = 'event-description';
    desc.style.cssText = 'font-size:.8rem;font-style:italic;color:var(--text-secondary);margin-top:.08rem';
    bodyEl.appendChild(desc);

    src.onmessage = function (e) {
        var data = JSON.parse(e.data);
        if (data.token) {
            desc.textContent += data.token;
        }
        if (data.done) {
            src.close();
        }
    };
    src.onerror = function () { src.close(); };
}
```

Called from `processEvent` for pre_match, goal, half_time, full_time after the
DOM element is inserted.

## Concurrency Consideration

Ollama is single-threaded. If N browsers watch the same match simultaneously:
- Each triggers its own streaming call
- Requests queue up in Ollama
- Total latency = N × per-request latency

**Mitigation**: add a DB flag `match_event.llm_requested = 1` set atomically
(UPDATE … WHERE llm_requested = 0). Only the first browser that wins the race
streams; others fall back to `refreshPendingUpdates` polling (existing mechanism).

This is a future optimization; for the typical single-user case it is not needed.

## Nginx / Caddy

Nginx must **not** buffer the SSE response:

```nginx
location ~ ^/index\.php {
    # existing proxy_pass ...
    proxy_buffering off;
    proxy_cache off;
}
```

Or per-route with `X-Accel-Buffering: no` header (already in the PHP sketch).

## Removal of LlmEnrichJob (for streamable events)

- `SimulateMatchJob`: remove `Yii::$app->queue->push(new LlmEnrichJob([...]))` calls for pre_match, half_time, full_time.
- Goal events: remove LlmEnrichJob push from MatchEngine.
- `LlmEnrichJob` class can be kept for potential non-live use (replay enrichment).
- `refreshPendingUpdates` in live.php: kept as fallback for late joiners.

## Implementation Notes (2026-05-19)

Implemented in:
- `v2/worker-go/engine/match.go`
  - `CallOllama(prompt, onToken)` now emits token callback while decoding stream chunks.
  - `enrichEventAsync(...)` now broadcasts:
    - `llm_stream_start`
    - `llm_stream_token`
    - `llm_stream_done`
  - final cleaned text still persisted to `match_event.detail.description`.
- `v2/views/fixture/live.php`
  - receives new `llm_stream_*` SSE messages;
  - renders progressive typing into `.event-description`;
  - finalizes with persisted description once `done` arrives.
