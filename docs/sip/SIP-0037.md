# SIP-0037 — Character Traits: Match & Training Effects

| Field   | Value                 |
|---------|-----------------------|
| Status  | Accepted (Implemented E2E) |
| Author  | Gold Manager Dev Team |
| Created | 2026-05-18            |

## Summary

Player character traits (already stored in `player.character`) affect two distinct systems:
1. **Match simulation** — modifiers on attack/defense duel probabilities (partially implemented in SIP-0024)
2. **Weekly training** — modifier on XP gain rate per skill category

This SIP extends the current partial implementation and formalises the full rule set.

---

## Character Trait Definitions

| Carattere | In partita | In allenamento |
|-----------|-----------|----------------|
| **Grintoso** | +10% attack when losing; +5% midfield win | +10% XP on physical skills (df, cn, tr) |
| **Ambizioso** | +5% all stats | +8% XP on all categories; morale drops if benched |
| **Razionale** | +5% away from home; +10% penalty accuracy | Normal XP |
| **Diligente** | +5% condition recovery | +15% XP on all categories; freshness −10% (trains harder) |
| **Corretto** | −30% yellow/red card probability | Normal XP; injury probability −20% |
| **Duttile** | −15% out-of-position penalty | Learns new positions 2× faster |
| **Inflessibile** | +10% in primary position | −20% XP on non-primary skills |
| **Introverso** | +5% when effort is low | −5% XP (dislikes group training) |
| **Carismatico** | +3% to ALL teammates within 2 zones | +5% XP to all teammates as captain |
| **Popolare** | Team morale +2 per match | +5% XP when team morale is high |
| **Costante** | Lower form variance (±5% instead of ±15%) | Consistent XP regardless of performance |
| **Irrequieto** | +10% home advantage | −10% XP when benched >2 matches; more red cards |

## Match Modifiers (detailed)

Applied in `MatchEngine::computePlayerMultiplier()`:

```php
switch (strtolower($player->character)) {
    case 'grintoso':
        $charBonus = $isLosing ? 1.10 : 1.00;
        break;
    case 'ambizioso':
        $charBonus = 1.05;
        break;
    case 'diligente':
        // Better condition but reduced freshness
        $condMult  *= 1.05;
        $freshMult *= 0.90;
        break;
    case 'costante':
        // Reduce variance: form effect is dampened
        $formMult = ($player->form / 100) * 0.15 + 0.85; // narrower range
        break;
    case 'irrequieto':
        $charBonus = $isHome ? 1.10 : 0.95;
        break;
    case 'inflessibile':
        // Bonus if in primary position, penalty if out of position
        $charBonus = $inPrimaryPosition ? 1.10 : 0.85;
        break;
    case 'carismatico':
        // Handled at team level: small bonus to adjacent zone players
        break;
}
```

## Training Modifiers

Applied in `EconomyController::applyWeeklyTraining()`:

```php
function characterTrainingMod(string $character, string $stat): float {
    return match (strtolower($character)) {
        'grintoso'  => in_array($stat, ['skill_df','skill_cn','skill_tr']) ? 1.10 : 1.00,
        'ambizioso' => 1.08,
        'diligente' => 1.15,
        'corretto'  => 1.00, // injury resist is separate
        'inflessibile' => in_array($stat, ['skill_po','skill_df','skill_cn','skill_pa','skill_rg','skill_cr','skill_tc','skill_tr'])
                         ? ($stat === primaryStatForPosition($character) ? 1.05 : 0.80)
                         : 1.00,
        'introverso'   => 0.95,
        'costante'     => 1.00, // variance reduction, not speed
        'irrequieto'   => $recentMatchesPlayed >= 2 ? 1.00 : 0.90,
        default        => 1.00,
    };
}
```

## Carismatico — Team Aura Effect

The `carismatico` character grants a small aura bonus to **adjacent formation slots**:
- Identify the carismatico player's zone
- For each adjacent zone (±1 row, ±1 column), apply +2% multiplier
- Applied after individual multipliers are computed
- If the player is also captain (`is_captain = true`): extends to entire team (+1%)

## Implementation Notes

- Training modifiers are centralized in `CharacterTraitHelper::trainingModifier()`.
- `irrequieto` bench penalty is applied from active-formation status (starter/non-starter), as pragmatic proxy for bench streak.
- `razionale` bonus on penalties is applied in set-piece precision cap logic.
- Go live engine applies a team-level trait scalar (average active XI traits) to stay aligned with PHP simulation intent.
