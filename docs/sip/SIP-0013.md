# SIP-0013: Match Event Sourcing

- Status: Accepted (Implemented)
- Type: Architecture
- Created: 2026-05-14

## Abstract

Define event-driven storage for matches.

## Motivation

Event sourcing allows replaying, debugging and analyzing matches.

## Specification

Matches SHALL be stored as ordered events.

Example:

- minute 1 kickoff
- minute 14 shot
- minute 15 goal
- minute 44 yellow card

## Benefits

- Replay support
- Live commentary
- Analytics
- Debugging
- Auditing

## Persistence

Events SHALL be immutable.

## Long term goals

- Live streaming
- Historical playback
- Real-time spectators
