# SIP-0002: Target Architecture

- Status: Accepted
- Type: Architecture
- Created: 2026-05-14

## Abstract

Define the target architecture for Gold Manager v2.

## Specification

The platform SHALL use:

- PHP 8.3
- Yii2
- Docker
- Nginx
- MariaDB/MySQL
- Redis

The application SHALL be divided into:

- Domain layer
- Service layer
- Persistence layer
- Presentation layer
- API layer

## Rationale

The architecture aims to improve maintainability, scalability and testability.

## Security considerations

- CSRF protection
- RBAC authorization
- JWT authentication for APIs
- Rate limiting

## Migration considerations

Legacy code SHALL be progressively replaced module by module.
