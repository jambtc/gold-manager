# SIP-0055 — Cron Container (Scheduled Tasks)

| Field   | Value                 |
|---------|-----------------------|
| Status  | Accepted (Implemented) |
| Author  | Gold Manager Dev Team |
| Created | 2026-05-19            |

## Summary

Add a dedicated `cron` Docker container that runs all periodic game-engine tasks
(wages, recovery, season rollover, fixture scheduling). Modelled 
cron pattern: same PHP image, `flock`-guarded jobs, log streaming, schedule overridable via env vars.

No host-level crontab is required.

---

## Jobs

| Job | Schedule | Command | Description |
|-----|----------|---------|-------------|
| pay-wages | `0 0 * * *` | `economy/pay-wages` | Deducts weekly salary from every team budget |
| weekly-recovery | `0 1 * * 1` | `economy/apply-weekly-recovery` | Decrements `injury_weeks` for all injured players |
| run-fixtures | `*/5 * * * *` | `game/run-fixtures` | Triggers pending fixture simulations |
| season-rollover | `0 3 * * 1` | `economy/season-rollover <id>` | Closed at season end — manual trigger or separate hook |

---

## Docker Service

Add to `docker-compose.yml`:

```yaml
  cron:
    build:
      context: .
      dockerfile: .docker/php/Dockerfile
    container_name: gold-manager-cron
    command: ["/bin/bash", "/var/www/html/docker/cron-entry.sh"]
    volumes:
      - .:/var/www/html
    environment:
      - APP_ENV=${APP_ENV:-prod}
      - DB_HOST=${DB_HOST:-db}
      - DB_NAME=${DB_NAME}
      - DB_USER=${DB_USER}
      - DB_PASSWORD=${DB_PASSWORD}
      - REDIS_HOST=${REDIS_HOST:-redis}
      - CRON_TZ=${CRON_TZ:-Europe/Rome}
      - CRON_ENABLED=${CRON_ENABLED:-1}
      # Per-job toggles
      - CRON_ENABLE_PAY_WAGES=${CRON_ENABLE_PAY_WAGES:-1}
      - CRON_ENABLE_WEEKLY_RECOVERY=${CRON_ENABLE_WEEKLY_RECOVERY:-1}
      - CRON_ENABLE_RUN_FIXTURES=${CRON_ENABLE_RUN_FIXTURES:-1}
      # Per-job schedule overrides
      - CRON_PAY_WAGES_SCHEDULE=${CRON_PAY_WAGES_SCHEDULE:-0 0 * * *}
      - CRON_WEEKLY_RECOVERY_SCHEDULE=${CRON_WEEKLY_RECOVERY_SCHEDULE:-0 1 * * 1}
      - CRON_RUN_FIXTURES_SCHEDULE=${CRON_RUN_FIXTURES_SCHEDULE:-*/5 * * * *}
    depends_on:
      - db
      - redis
    restart: unless-stopped
```

## Entrypoint Script (`docker/cron-entry.sh`)

```bash
#!/usr/bin/env bash
set -euo pipefail

ROOT="/var/www/html/v2"
TMP_CRON="/tmp/gold-manager-cron"
CRON_ENABLED="${CRON_ENABLED:-1}"
CRON_TZ="${CRON_TZ:-Europe/Rome}"
FLOCK="$(command -v flock || true)"
LOCKS="${ROOT}/../runtime/locks"
LOGS="${ROOT}/../runtime/logs"

mkdir -p "$LOCKS" "$LOGS"

register_job() {
  local enabled="$1" schedule="$2" cmd="$3" log="$4" label="$5"
  [[ "$enabled" != "1" ]] && { echo "[cron] disabled: $label"; return; }
  [[ -z "$schedule" ]]    && { echo "[cron] no schedule: $label"; return; }
  local guarded="mkdir -p $LOCKS $LOGS"
  if [[ -n "$FLOCK" ]]; then
    guarded+=" && $FLOCK -n $LOCKS/${label}.lock -c 'cd $ROOT && $cmd'"
  else
    guarded+=" && cd $ROOT && $cmd"
  fi
  echo "$schedule $guarded >> $LOGS/${label}.log 2>&1" >> "$TMP_CRON"
  touch "$LOGS/${label}.log"
  echo "[cron] enabled: $label ($schedule)"
}

{
  echo "SHELL=/bin/bash"
  echo "PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin"
  echo "CRON_TZ=${CRON_TZ}"
} > "$TMP_CRON"

register_job \
  "${CRON_ENABLE_PAY_WAGES:-1}" \
  "${CRON_PAY_WAGES_SCHEDULE:-0 0 * * *}" \
  "php yii economy/pay-wages" \
  "$LOGS/pay-wages.log" \
  "pay-wages"

register_job \
  "${CRON_ENABLE_WEEKLY_RECOVERY:-1}" \
  "${CRON_WEEKLY_RECOVERY_SCHEDULE:-0 1 * * 1}" \
  "php yii economy/apply-weekly-recovery" \
  "$LOGS/weekly-recovery.log" \
  "weekly-recovery"

register_job \
  "${CRON_ENABLE_RUN_FIXTURES:-1}" \
  "${CRON_RUN_FIXTURES_SCHEDULE:-*/5 * * * *}" \
  "php yii game/run-fixtures" \
  "$LOGS/run-fixtures.log" \
  "run-fixtures"

crontab "$TMP_CRON"
echo "[cron] $(grep -Ecv '^(#|$|[A-Za-z_]+=)' "$TMP_CRON") job(s) loaded."

cleanup() { kill "$CRON_PID" "$TAIL_PID" 2>/dev/null || true; }
trap cleanup EXIT INT TERM

if [[ "$CRON_ENABLED" != "1" ]]; then
  echo "[cron] CRON_ENABLED=0 — sleeping."
  exec tail -f /dev/null
fi

cron -f &
CRON_PID=$!

LOG_FILES=("$LOGS/pay-wages.log" "$LOGS/weekly-recovery.log" "$LOGS/run-fixtures.log")
tail -n 0 -F "${LOG_FILES[@]}" &
TAIL_PID=$!

wait -n "$CRON_PID" "$TAIL_PID"
```

## Directory Layout

```
gold-manager/
├── docker/
│   └── cron-entry.sh          ← entrypoint (new)
├── runtime/
│   ├── logs/
│   │   ├── pay-wages.log
│   │   ├── weekly-recovery.log
│   │   └── run-fixtures.log
│   └── locks/
│       ├── pay-wages.lock
│       ├── weekly-recovery.lock
│       └── run-fixtures.lock
└── docker-compose.yml          ← add `cron` service
```

Add `runtime/logs/` and `runtime/locks/` to `.gitignore`.

---

## Dockerfile requirement

The PHP image must have `cron` installed. Add to `.docker/php/Dockerfile`:

```dockerfile
RUN apt-get install -y cron
```

(`flock` is already available in `util-linux` which is installed by default.)

## Acceptance Criteria

- [ ] `docker/cron-entry.sh` exists and is executable
- [ ] `cron` service added to `docker-compose.yml`
- [ ] `apt-get install -y cron` added to `.docker/php/Dockerfile`

- [ ] `gold-manager-cron` container starts and loads jobs without error
- [ ] `docker logs gold-manager-cron` shows `[cron] 3 job(s) loaded.`
- [ ] `economy/pay-wages` runs daily at midnight
- [ ] `economy/apply-weekly-recovery` runs Monday at 01:00
- [ ] `game/run-fixtures` runs every 5 minutes
- [ ] `flock` prevents overlapping runs of the same job
- [ ] Logs visible via `docker logs gold-manager-cron` (streamed by `tail -F`)
- [ ] Each job independently toggleable via `CRON_ENABLE_*` env var
- [ ] Schedule overridable via `CRON_*_SCHEDULE` env var (useful for dev/staging)

## Dev Speedup

In `.env.local` (dev environment), override schedules to run more frequently:

```env
CRON_WEEKLY_RECOVERY_SCHEDULE=* * * * *   # ogni minuto in dev
CRON_PAY_WAGES_SCHEDULE=*/10 * * * *
```
