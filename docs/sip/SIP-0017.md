# SIP-0017: Mobile Application Support

- Status: Draft
- Type: Mobile
- Created: 2026-05-14

## Abstract

Define support for future mobile applications.

## Goals

- Shared APIs
- Push notifications
- Responsive UX
- Mobile-friendly authentication

## Requirements

The backend SHALL expose stable APIs consumable by mobile clients.
