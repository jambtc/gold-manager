## Staff Stat: Efficiency

Each staff member has a single `efficiency` stat (1–100).

Determined at hire by:
- Base level: `rand(30, 90)` depending on market tier
- Decays –1/season if `salary < market_rate`
- Grows +1/season if `salary > market_rate * 1.2`
- Hard cap: 99

## Match Bonus Formulas (restored from `1vs1.php`)

Applied to team department totals **after** base computation, **before** match simulation:

```php
// Coefficients from GU Classic
$b_coach     = 0.30  * $efficiency;   // Head Coach
$b_assistant = $efficiency / 30.3;    // Vice Allenatore
$b_gkcoach   = 0.035 * $efficiency;  // Allenatore Portieri

// Applied per department:
$GK  = $GK  * (1 + ($b_assistant + $b_gkcoach)            / 100);
$DEF = $DEF * (1 + ($b_assistant + $b_coach * $spec[0])    / 100);
$MID = $MID * (1 + ($b_assistant + $b_coach * $spec[1])    / 100);
$ATT = $ATT * (1 + ($b_assistant + $b_coach * $spec[2])    / 100);
```

Where `$spec[0..2]` is the coach's specialisation array (sums to 1.0):

| Specialisation | DEF | MID | ATT |
|----------------|-----|-----|-----|
| Difensivista   | 0.6 | 0.3 | 0.1 |
| Equilibrato    | 0.33| 0.33| 0.33|
| Offensivista   | 0.1 | 0.3 | 0.6 |

## Training Bonus (applied weekly by EconomyController)

| Role | Training bonus |
|------|---------------|
| Head Coach | +10% XP gain on tactical drills |
| Assistant Coach | +5% XP on all skill drills |
| GK Coach | +15% XP on goalkeeper skill drills |
| Fitness Coach | Freshness recovery +1/week per player |
| Doctor | Injury recovery ×2 speed |
