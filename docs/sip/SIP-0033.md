# SIP-0033 — SVG Skill & Position Icon System

| Field   | Value                 |
|---------|-----------------------|
| Status  | Implemented ✅             |
| Author  | Gold Manager Dev Team |
| Created | 2026-05-18            |

## Summary

Replace all legacy PNG icons (from `newGM/images/`) with inline SVG icons embedded
directly in the PHP views. This eliminates HTTP requests, allows colour theming via
CSS variables, and enables responsive sizing.

Two icon families (both now live in formation + player views):
1. **Position icons** (`r*.png`) — the player's field role
2. **Skill/talent icons** (`t_*.png`) — special abilities

## Design Principles

All SVGs:
- `viewBox="0 0 24 24"` — consistent size
- Current colour via `currentColor` → inherits from CSS
- Rendered inline in PHP (no `<img>` tag, no HTTP request)
- Accessible: `<title>` + `role="img"` + `aria-label`

### Example — Velocità

```svg
<svg viewBox="0 0 24 24" role="img" aria-label="Velocità" width="20" height="20">
  <title>Velocità</title>
  <path fill="currentColor" d="M13 2L3 14h9l-1 8 10-12h-9l1-8z"/>
</svg>
```

### Example — Portiere (position)

```svg
<svg viewBox="0 0 24 24" role="img" aria-label="Portiere" width="20" height="20">
  <title>Portiere</title>
  <!-- Goalkeeper gloves shape -->
  <rect x="3" y="8" width="8" height="12" rx="2" fill="currentColor" opacity=".3"/>
  <rect x="13" y="8" width="8" height="12" rx="2" fill="currentColor" opacity=".3"/>
  <rect x="3" y="6" width="18" height="3" rx="1" fill="currentColor"/>
</svg>
```

## Implementation

### Component file

Create `v2/components/SvgIcons.php`:

```php
class SvgIcons
{
    public static function position(string $role, int $size = 20): string
    public static function skill(string $skillCode, int $size = 20): string
    public static function foot(string $foot, int $size = 16): string
}
```

### Usage in views

```php
// In formation view player card:
echo SvgIcons::position($player->position, 18);
echo SvgIcons::skill('velocita', 16);
```

### Position → zone mapping (used by position hint)

```
Portiere  → zone row 9, col 4 (centre bottom)
Difensore → zone rows 7-8
Centrocampista → zone rows 4-6
Attaccante → zone rows 1-3
Ala       → zone cols 1-2 or 6-7 (flanks)
```
