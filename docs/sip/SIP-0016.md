# SIP-0016: Plugin System

- Status: Draft
- Type: Architecture
- Created: 2026-05-14

## Abstract

Define extension capabilities for Gold Manager v2.

## Goals

- Custom competitions
- Modular features
- Theme support
- Gameplay extensions

## Plugin areas

- UI widgets
- Notifications
- External APIs
- Reporting

## Constraints

Plugins SHALL respect application permissions and security policies.
