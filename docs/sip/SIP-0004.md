# SIP-0004: Database and Migrations

- Status: Draft
- Type: Database
- Created: 2026-05-14

## Abstract

Define database migration strategy.

## Specification

All schema changes SHALL use Yii2 migrations.

Direct production schema modifications are forbidden.

## Database conventions

- snake_case naming
- bigint primary keys
- created_at and updated_at timestamps
- soft delete where required

## Migration strategy

Legacy tables SHALL be mapped and normalized progressively.
