# SIP-0036 — Player Training System: Skill & Tactical Weekly Training

| Field   | Value                 |
|---------|-----------------------|
| Status  | Implemented ✅             |
| Author  | Gold Manager Dev Team |
| Created | 2026-05-18            |

## Summary

The manager allocates weekly training points across two panels:
1. **Skill training** — improves individual player stats (po, df, cn, pa, rg, cr, tc, tr)
2. **Tactical training** — improves team collective tactics (pressing, possession, etc.)

Staff quality multiplies the XP gained. Training is processed daily by `EconomyController::actionApplyDailyTraining()` (legacy alias `apply-weekly-training` retained).

Source: `gu-classic/allena_skill.php`, `allena_tattiche.php`, `data_allenamento_aggiorna.php`.

---

## Training Points Budget

Each week the manager has **100 total training points** to distribute across all categories.
Points can be split freely (e.g., 30 skill + 70 tactics, or 100 skill + 0 tactics).

Point → % conversion (from GU Classic formula):
```
% = round(points × 0.3067)   // 326 points = 100%
```

### XP Gain Formula

Applied weekly by `EconomyController::actionRunCron()`:

```php
foreach ($players as $player) {
    $base_xp = $allocation[$stat] / 100;        // 0.0 – 1.0
    $age_mod  = 1 - max(0, ($player->age - 25) * 0.02); // older → slower
    $staff_mod = 1 + $assistant_coach_efficiency / 100 * 0.05;
    $char_mod  = $this->characterTrainingMod($player->character, $stat);
    $xp = round($base_xp * $age_mod * $staff_mod * $char_mod, 2);
    // Cap: stat cannot exceed 99
    $player->$stat = min(99, $player->$stat + $xp);
}
```

Character modifiers → see [[SIP-0037]].

### DB Schema

```sql
CREATE TABLE training_skill (
  id            INT AUTO_INCREMENT PRIMARY KEY,
  team_id       INT NOT NULL,

  alloc_cond    TINYINT NOT NULL DEFAULT 0,
  alloc_po      TINYINT NOT NULL DEFAULT 0,
  alloc_df      TINYINT NOT NULL DEFAULT 0,
  alloc_cn      TINYINT NOT NULL DEFAULT 0,
  alloc_pa      TINYINT NOT NULL DEFAULT 0,
  alloc_rg      TINYINT NOT NULL DEFAULT 0,
  alloc_cr      TINYINT NOT NULL DEFAULT 0,
  alloc_tc      TINYINT NOT NULL DEFAULT 0,
  alloc_tr      TINYINT NOT NULL DEFAULT 0,
  updated_at    INT NOT NULL
);
```

## Part B — Tactical Training

### Categories (8 sliders, from GU Classic `allena_tattiche.php`)

| Slider | Tactical concept | Effect in match |
|--------|-----------------|-----------------|
| Pressing | High press on opponent | +% on midfield duel win rate |
| Contropiede | Counter-attack | +% attack speed bonus |
| Possesso palla | Ball possession | +% midfield dominance |
| Gioco palla bassa | Short passing game | +% passing success |
| Lancio lungo | Long ball / direct play | +% bypass midfield chance |
| Catenaccio | Ultra-defensive | +% defensive wall |
| Trappola fuorigioco | Offside trap | Offside chance on opponent attack |
| Calci piazzati | Set pieces | +% from free kicks / corners |

### Tactical Level → Match Modifier

```
modifier = round(alloc_val × 0.3067)  // % level (0-100)
match_bonus = level / 100 × max_effect
```

`max_effect` per tactic: see [[SIP-0038]].

### DB Schema

```sql
CREATE TABLE training_tactic (
  id           INT AUTO_INCREMENT PRIMARY KEY,
  team_id      INT NOT NULL,
  season       INT NOT NULL DEFAULT 1,
  -- current tactic levels (0-100, applying staff bonus)
  pressing     TINYINT NOT NULL DEFAULT 0,
  contropiede  TINYINT NOT NULL DEFAULT 0,
  possesso     TINYINT NOT NULL DEFAULT 0,
  palla_bassa  TINYINT NOT NULL DEFAULT 0,
  lancio_lungo TINYINT NOT NULL DEFAULT 0,
  catenaccio   TINYINT NOT NULL DEFAULT 0,
  fuorigioco   TINYINT NOT NULL DEFAULT 0,
  calci_piazzati TINYINT NOT NULL DEFAULT 0,
  updated_at   INT NOT NULL
);
```

## UI — Training Panel

Two tabs:
1. **Fisico** (Skill training) — 10 sliders with progress bars showing current stat + projected gain
2. **Tattico** (Tactical training) — 8 sliders with level bars and match effect description

Point budget counter: `Punti usati: 67/100` — prevents over-allocation.

Staff bonus shown inline: *"Allenatore: +4.2% XP / Vice: +1.6% XP"*
