# SIP-0093 — Squadra Primavera / Youth Team

## Obiettivo

Ogni club professionistico ha un settore giovanile. Introdurre una **squadra Primavera**
virtuale collegata al team principale, con:

- Rosa di giovani (età 15–19) generata automaticamente
- Torneo Primavera separato (round-robin intra-season)
- Promozione in prima squadra tramite contratto

---

## Funzionalità

### 1. Roster Primavera

- Ogni team umano ha 15–20 giovani nel vivaio (`is_youth = 1` su `player`)
- Generati automaticamente a inizio stagione (`WorldSeeder`)
- Statistiche separate: non contano nel campionato principale
- Allenamento condiviso con la prima squadra (stesso `training_snapshot`)

### 2. Torneo Primavera

- Competizione di tipo `youth` nella stessa `competition` structure
- Round-robin stagionale, 16 squadre (una per ogni club partecipante)
- Partite giocate dal Go worker in modo asincrono (bassa priorità)
- Classifica separata

### 3. Promozione in prima squadra

- Il manager può "promuovere" un giovane → crea contratto attivo
- Costo: stipendio minimo × 2 (bonus ingaggio)
- Il giovane mantiene i talenti maturati nel settore giovanile

### 4. Prestito dal vivaio

- Un giovane può essere ceduto in prestito ad altri team
- Quota prestito: 0 (gratuito per sviluppo)
- Al rientro: se ha giocato ≥ 10 partite → forma +5, condition +5

---

## Data model

### `player`
```sql
ALTER TABLE player ADD COLUMN is_youth TINYINT(1) NOT NULL DEFAULT 0;
ALTER TABLE player ADD COLUMN youth_team_id INT UNSIGNED NULL; -- FK → team (genitore)
```

### `competition`
- Nuovo tipo: `type = 'youth'`
- `country_code` dal team principale
