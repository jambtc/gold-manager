# SIP-0012: AI Controlled Teams

- Status: Accepted (Implemented)
- Type: AI
- Created: 2026-05-14

## Abstract

Define behavior for AI controlled teams.

## Goals

- Competitive gameplay
- Dynamic leagues
- Autonomous transfers
- Tactical adaptation

## AI responsibilities

- Squad selection
- Formation changes
- Transfer decisions
- Budget management
- Contract renewals
- Youth development

## Difficulty levels

- Casual
- Normal
- Competitive
- Hardcore

## Long term goals

- Machine-learning assisted balancing
- Adaptive tactical systems

## Implementation status (2026-05-27)

Implemented end-to-end in current gameplay stack:

- CPU squad maintenance:
  - automatic active formation preparation before fixtures
  - hard role constraints in auto-assignment (GK/DF/MF/FW slots respected)
  - fallback warning path when role coverage is missing
- CPU pre-match setup:
  - difficulty resolution (`casual`, `normal`, `competitive`, `hardcore`) by tier + standing rank
  - module/style/focus suggestion based on roster availability + trained tactics
  - auto-update of marking/offside/trained tactic before simulation
- CPU live match behavior:
  - automatic tactical changes by scoreline/time
  - automatic substitutions by minute windows + freshness thresholds
  - aggressiveness/scenario timing tuned by resolved CPU difficulty profile
- Economy/training/staff/transfer/friendly autonomous logic:
  - covered by SIP-0051 implementation and daily jobs.

## Notes

- Human managers keep manual control.
- CPU automation only targets teams marked `is_cpu=1`.
- PHP/Go parity pre-push check remains mandatory (`v2/scripts/check-engine-parity-pre-push.sh`).
