# SIP-0056 — Sponsor Management v2

| Field   | Value                 |
|---------|-----------------------|
| Status  | Accepted (Implemented) |
| Author  | Gold Manager Dev Team |
| Created | 2026-05-19            |

## Summary

Definire un sistema sponsor completo e coerente con economia stagionale:

1. mercato sponsor con offerte differenziate per tier/ranking/reputazione;
2. negoziazione, firma, rinnovo e rescissione contratti sponsor;
3. payout periodico integrato nel ciclo economico;
4. eventi/notizie sponsor nel feed manager.

## Scope

- Offerte sponsor filtrate per prestigio squadra (`prestige_required`).
- Contratti `team_sponsor` con stati `active|expired|terminated`.
- Durata contratti in stagioni e scadenza automatica.
- Payout periodico integrato nel tick economia settimanale.
- UI manager con tab Attivo / Offerte / Storico.
- News feed eventi sponsor (firma, rinnovo, rescissione, scadenza).

## Core Rules

- Ogni team può avere max 1 sponsor principale attivo.
- Offerte sponsor vengono ribilanciate a inizio stagione (pool annuale) e possono sparire se non usate.
- Offerte filtrate per prestigio club (`prestige_required`).
- Contratti con durata in stagioni, rinnovo e rescissione anticipata con penale.
- Payout settimanale = `base_payment / 26`, applicato solo a contratti attivi non scaduti.

## Acceptance Criteria

- [x] Flusso completo offerte sponsor (lista, selezione, firma, scadenza).
- [x] Payout periodico calcolato e registrato in economia.
- [x] Rinnovo / cambio sponsor gestiti senza inconsistenze.
- [x] Storico sponsor consultabile da manager.
- [x] Eventi sponsor pubblicati in news feed (SIP-0050).
