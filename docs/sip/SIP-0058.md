# SIP-0058 — Telegram Notifications

| Field   | Value                 |
|---------|-----------------------|
| Status  | Accepted (Implemented) |
| Author  | Gold Manager Dev Team |
| Created | 2026-05-20            |

## Summary

Each manager can link their Gold Manager account to a personal Telegram chat.
Once linked, the bot sends push notifications for all relevant in-game events
without requiring the manager to keep the browser open.

---

## Architecture

```
Gold Manager PHP ──► TelegramService::send($chatId, $message)
                              │
                              └──► Telegram Bot API (HTTPS)
                                       │
                                       └──► Manager's Telegram app
```

- **Bot**: one shared bot (`@GoldManagerBot`) configured via `GM_TELEGRAM_TOKEN`
- **Chat ID**: stored per user in `user.telegram_chat_id` (nullable INT)
- **Linking flow**: `/start` command on the bot → one-time token → user pastes in profile → verified

No webhook needed for notifications (outgoing only). Webhook optional for future
two-way commands (e.g. `/lineup`, `/score`).

## TelegramService

```php
class TelegramService
{
    private const API = 'https://api.telegram.org/bot';

    public static function isConfigured(): bool
    {
        return !empty(getenv('GM_TELEGRAM_TOKEN'));
    }

    public static function send(int $chatId, string $text, bool $silent = false): bool
    {
        $token = getenv('GM_TELEGRAM_TOKEN');
        if (!$token || !$chatId) return false;

        $payload = [
            'chat_id'              => $chatId,
            'text'                 => $text,
            'parse_mode'           => 'HTML',
            'disable_notification' => $silent,
        ];

        $ctx = stream_context_create(['http' => [
            'method'  => 'POST',
            'header'  => "Content-Type: application/json\r\n",
            'content' => json_encode($payload),
            'timeout' => 5,
        ]]);

        @file_get_contents(self::API . $token . '/sendMessage', false, $ctx);
        return true;
    }

    public static function sendToUser(int $userId, string $text, bool $silent = false): bool
    {
        $user = \app\models\User::findOne($userId);
        if (!$user || !$user->telegram_chat_id || !$user->telegram_notify) return false;
        return self::send((int) $user->telegram_chat_id, $text, $silent);
    }

    public static function generateLinkToken(int $userId): string
    {
        $token = bin2hex(random_bytes(16));
        \app\models\User::updateAll(['telegram_link_token' => $token], ['id' => $userId]);
        return $token;
    }

    public static function verifyAndLink(string $token, int $chatId): bool
    {
        $user = \app\models\User::findOne(['telegram_link_token' => $token]);
        if (!$user) return false;
        $user->telegram_chat_id   = $chatId;
        $user->telegram_link_token = null;
        return $user->save(false);
    }
}
```

## Linking Flow (User Profile)

1. Manager visits `/user/profile`
2. Clicks **"Collega Telegram"**
3. Server generates a 32-char token, stores in `user.telegram_link_token`
4. UI shows: *"Apri [@GoldManagerBot](https://t.me/GoldManagerBot) e invia: `/start GM-{token}`"*
5. Bot receives `/start GM-{token}`:
   - Verifies token → updates `telegram_chat_id` → sends welcome message
   - Handled by a webhook endpoint: `POST /telegram/webhook`

### Minimal Webhook (for /start only)

```php
// TelegramController::actionWebhook()
public function actionWebhook(): Response
{
    $data = json_decode(Yii::$app->request->rawBody, true);
    $text = $data['message']['text'] ?? '';
    $chatId = $data['message']['chat']['id'] ?? null;

    if ($chatId && str_starts_with($text, '/start GM-')) {
        $token = substr($text, 10);
        if (TelegramService::verifyAndLink($token, (int) $chatId)) {
            TelegramService::send((int) $chatId,
                "✅ <b>Account collegato!</b>\nRiceverai notifiche su questo chat."
            );
        }
    }
    return $this->asJson(['ok' => true]);
}
```

Caddy route: `POST /telegram/webhook` → nginx → PHP (no auth, Telegram IPs only).

## Notification Settings (User Profile)

Toggle per categoria nel profilo:

```
☑ Partite (goal, inizio, fine)
☑ Infortuni e cartellini
☑ Mercato (offerte)
☑ Amichevoli (inviti)
☑ Rapporti scout
☑ Riepilogo settimanale
```

Stored as bitmask in `user.telegram_notify` (INT, 1=all, 0=none) or as JSON column.
For simplicity v1: single toggle (all or nothing).
