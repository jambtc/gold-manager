## Summary

`calci_piazzati` è una skill individuale del giocatore (non una tattica di squadra).
I giocatori la allenano tramite il sistema `training_skill.alloc_calci_piazzati`.
Durante la partita, quando c'è una punizione o un rigore, la skill del battitore
determina la probabilità di segnare.

---

## Colonne DB

### `player.skill_cp` (TINYINT UNSIGNED, default 0)
Skill set piece del singolo giocatore. Range 0–100.

### Rimosso
- `training_tactic.calci_piazzati` — eliminato (era team-level, ora è player-level)
- `training_tactic_snapshot.calci_piazzati` — eliminato

---

## Allenamento

Il flusso rimane invariato:
1. Il manager alloca punti in `training_skill.alloc_calci_piazzati`
2. `EconomyController::actionApplyDailyTraining()` usa il map `'alloc_calci_piazzati' => 'skill_cp'`
3. I giocatori guadagnano XP su `skill_cp` con la stessa curva di crescita delle altre skill

Il talento `calci_piazzati` in `PlayerAttributeHelper` già agisce su `alloc_calci_piazzati`.

---

## Formula — Precision Cap (PHP)

In `FormationRoleHelper::precisionCapForSetPiece()`:

```
Battitore assente:
  freekick: precisionCap = 30
  penalty:  precisionCap = 45

Con battitore (skill_cp = 0..100):
  freekick: precisionCap = min(60, 30 + floor(skill_cp × 0.30))  → [30, 60]
  penalty:  precisionCap = min(70, 45 + floor(skill_cp × 0.25))  → [45, 70]
```

Bonus ulteriori in `MatchEngine`:
- Carattere `razionale` su penalty: `min(70, precisionCap + 10)`
- Hard cap finale: `min(65, precisionCap)` su freekick (già garantito dalla formula)

Il gate di precisione: `mt_rand(1,100) > precisionCap` → miss.

---

## Parity Go

`teamSetPieceMod(teamID, fixtureID)` — restituisce un moltiplicatore `[1.0, 1.06]`
basato sul massimo `skill_cp` dell'XI attivo del team.

```
setPieceMod = 1.0 + (maxSkillCp / 100) × 0.06
```

Applicato ai threshold di gol:
```
homeGoalThreshold = 2.5 × homeBonus × homeGoalMod × homeSetPieceMod
awayGoalThreshold = homeGoalThreshold + 2.5 × awayBonus × awayGoalMod × awaySetPieceMod
```
