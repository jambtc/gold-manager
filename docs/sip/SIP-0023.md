## Summary

Managers can make real-time decisions during a live match via a Command Channel:
substitutions, tactical style changes, and intensity overrides.
Commands are written to the DB by PHP and consumed by the Go worker on the next tick.

## Architecture

### 1. `match_command` table

| Column              | Type    | Notes                          |
|---------------------|---------|--------------------------------|
| `fixture_id`        | int     | FK → fixture                   |
| `team_id`           | int     | issuing team                   |
| `command_type`      | varchar | `substitution` / `tactic` / …  |
| `payload`           | json    | command detail                 |
| `processed`         | tinyint | 0 = pending, 1 = done          |
| `executed_at_minute`| int     | minute consumed by Go worker   |

### 2. `LiveActionController` (PHP)

- `actionRoster(fixtureId)` — returns available bench players.
- `actionSubstitution(fixtureId)` — validates + inserts substitution command.
- `actionTactic(fixtureId)` — inserts tactic/style change command.

### 3. Go consumer (`match.go`)

At the start of every tick, the worker:

1. Fetches `WHERE fixture_id = ? AND processed = 0 LIMIT 10`.
2. Applies substitutions (swaps player in active formation slots).
3. Applies tactic overrides (modifies team trait/tactic profile for the tick).
4. Marks commands `processed = 1`.

### 4. PHP fallback (`MatchEngine::applyPendingActions`)

PHP engine also reads `pending_home_actions` / `pending_away_actions` from `match_state`
for matches that run under the PHP tick path.

### 5. UI (`views/fixture/live.php`)

- Tactical sidebar with **Defensive / Balanced / Offensive** quick buttons.
- Substitution panel: dropdown player-out + player-in, confirm button.
- Real-time status feedback (`#live-action-status`).

## Acceptance Criteria

- [x] Manager can submit a substitution during a live match.
- [x] Go worker reflects the substitution in the next minute's event stream.
- [x] Tactical style changes modify win probabilities immediately.
- [x] CPU AI also queues live actions (`queueCpuLiveActions`).
