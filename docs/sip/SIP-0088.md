# SIP-0088 — Sequenza Piazzati PHP completa

## Stato

Done — implementato in `MatchEngine.php`.

## Problema

Il worker Go live ora gestisce `corner`, `freekick` e `penalty_awarded` come
azioni pendenti: il tick successivo risolve il piazzato prima della normale
azione random.

Il motore PHP legacy invece risolve rigori/punizioni dentro la stessa fase di
tiro. Questo mantiene parita' di probabilita' base, ma non ancora parita' di
sequenza evento -> esito.

## Obiettivo

Portare anche `MatchEngine.php` a:

1. generare evento di assegnazione piazzato (`corner`, `freekick`,
   `penalty_awarded`);
2. salvare una pending set-piece action in `match_state`;
3. risolverla al tick successivo con evento `goal`, `gk_save`, `near_miss`,
   `penalty_miss` o `attack_attempt`;
4. usare sempre giocatori della formazione live, non della rosa generica;
5. mantenere statistiche: gol, rigori segnati/sbagliati, parate portiere.

## Regole target

- Rigore: `74% goal`, `16% parata`, `10% errore`.
- Punizione: `16% goal`, `26% parata`, `30% fuori`, resto respinta.
- Corner: `10% goal`, `25% parata`, `33% fuori`, resto respinta.
