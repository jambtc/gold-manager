# SIP-0054 — Daily Training Cycle

| Field   | Value                 |

## Summary

Replace the current weekly training model (SIP-0036) with a **daily training cycle**.
Each day the manager sets a focus that is locked at midnight and applied automatically.
In a typical week (match to match) there are **6 training days** with independent effects —
including both improvement when trained and decay when neglected.

---

## Weekly Structure

```
Mon   Tue   Wed   Thu   Fri   Sat   Sun
 T1    T2    T3    T4    T5    T6    MATCH
 ↑midnight effects applied each night
```

- **6 training days** per week (or days between fixtures, variable)
- **Match day**: no training, only recovery (doctor applies)
- Training sessions can be changed any time before midnight of each day
- At midnight: the day's allocation is **locked and applied**

---

## Daily Training Record

Replace `training_skill` (season-level) with a per-day record:

```sql
CREATE TABLE training_day (
  id            INT AUTO_INCREMENT PRIMARY KEY,
  team_id       INT NOT NULL,
  training_date DATE NOT NULL,
  -- Physical allocation (total must be ≤ 100)
  alloc_forma   TINYINT NOT NULL DEFAULT 0,
  alloc_cond    TINYINT NOT NULL DEFAULT 0,
  alloc_po      TINYINT NOT NULL DEFAULT 0,
  alloc_df      TINYINT NOT NULL DEFAULT 0,
  alloc_cn      TINYINT NOT NULL DEFAULT 0,
  alloc_pa      TINYINT NOT NULL DEFAULT 0,
  alloc_rg      TINYINT NOT NULL DEFAULT 0,
  alloc_cr      TINYINT NOT NULL DEFAULT 0,
  alloc_tc      TINYINT NOT NULL DEFAULT 0,
  alloc_tr      TINYINT NOT NULL DEFAULT 0,
  -- Tactical allocation (separate budget, ≤ 100)
  tactic_press  TINYINT NOT NULL DEFAULT 0,
  tactic_poss   TINYINT NOT NULL DEFAULT 0,
  tactic_caten  TINYINT NOT NULL DEFAULT 0,
  -- applied: true once midnight processing runs
  applied       TINYINT NOT NULL DEFAULT 0,
  created_at    INT NOT NULL,
  UNIQUE KEY uq_team_date (team_id, training_date)
);
```

## Midnight Processing (`EconomyController::applyDailyTraining()`)

Runs every midnight via cron/scheduled job:

```php
$today = date('Y-m-d');
$sessions = TrainingDay::find()
    ->where(['training_date' => $today, 'applied' => 0])
    ->all();

foreach ($sessions as $session) {
    $team = Team::findOne($session->team_id);
    $staffBonus = $this->computeStaffBonus($team->id); // SIP-0035

    foreach ($team->players as $player) {
        $ageMod = 1.0 - max(0, ($player->age - 25) * 0.02);
        $charMod = MatchEngine::characterTrainingMod($player->character, 'skill_tr'); // SIP-0037

        // XP gain per stat (1/6 of the old weekly formula per day)
        foreach ($statMap as $alloc => $stat) {
            $points = $session->$alloc; // 0-100
            $xp = ($points / 100) * $ageMod * $charMod * $staffBonus['physical'] / 6;
            if ($xp > 0) {
                $player->$stat = min(99, $player->$stat + $xp);
            }
        }

        // DECAY: skills NOT trained decay slightly
        foreach ($untrained as $stat) {
            $player->$stat = max(1, $player->$stat - 0.05); // -0.05 per day
        }

        $player->save(false);
    }

    $session->applied = 1;
    $session->save(false);
}
```

### Decay Rule

If a skill's daily allocation is 0, it decays by **−0.05 per day** (−0.30 per week).
A skill trained at 10 pts/day gains ~+0.02/day (net +0.15 per week after decay).
This encourages balanced training — total neglect of any skill causes gradual regression.

### Match Day Recovery

On match day (no `training_day` record):
- Freshness: `+5` (rest)
- Condition: `+3`
- Form: recalculated from match result (win → +3, draw → 0, loss → −2)
