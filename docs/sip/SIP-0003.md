# SIP-0003: Domain Model

- Status: Accepted (Implemented)
- Type: Domain
- Created: 2026-05-14

## Abstract

Define the main entities of Gold Manager v2.

## Core entities

- User
- Team
- Player
- Competition
- Season
- Fixture
- Match
- Standing
- Contract
- Transfer
- Stadium
- FinanceTransaction

## Rules

- Teams own players through contracts.
- Competitions contain seasons.
- Seasons contain fixtures.
- Fixtures generate matches.
- Matches update standings.

## Goals

The domain model SHALL remain independent from UI frameworks.
