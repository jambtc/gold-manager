## Summary

The manager sets a tactical philosophy for their team that modifies
how the match engine resolves each phase of play.
Restored from `gu-classic/allena_tattiche.php` and `data_allenamento_aggiorna.php`.

Each tactic has a **level** (0–100%) set via the training panel (see [[SIP-0036]])
and an **in-match effect** applied in `MatchEngine::resolveTick()`.

---

## Tactical Parameters

### 8 Team Tactics (from legacy `allena_tattiche` table)

| Tactic | Level field | Max effect | Phase affected |
|--------|-------------|------------|----------------|
| **Pressing** | `pressing` | +8% midfield win rate | Step 1: midfield duel |
| **Contropiede** | `contropiede` | +15% attack speed on transition | Step 2: attack side |
| **Possesso palla** | `possesso` | +10% midfield win rate | Step 1: midfield duel |
| **Gioco palla bassa** | `palla_bassa` | −5% opponent attack force | Step 3: attack vs defence |
| **Lancio lungo** | `lancio_lungo` | 20% chance to bypass midfield entirely | Step 1 skip |
| **Catenaccio** | `catenaccio` | +12% defence force | Step 3: attack vs defence |
| **Trappola fuorigioco** | `fuorigioco` | 15% chance to negate attack attempt | Step 2 |
| **Calci piazzati** | `calci_piazzati` | +20% goal probability from set pieces | Step 5: precision gate |

## Match Engine Integration

### Step 1 — Midfield Duel (pressing, possesso, lancio lungo)

```php
// Pressing bonus
$atkMid = $atk['cn'] + $atk['rg'] + $atk['pa'];
$atkMid *= (1 + $tactics['pressing'] / 100 * 0.08);
$atkMid *= (1 + $tactics['possesso'] / 100 * 0.10);

// Lancio lungo: chance to skip midfield entirely
if (mt_rand(1, 100) <= ($tactics['lancio_lungo'] * 0.20)) {
    // Skip to Step 3 directly (attack reaches area)
    goto step3;
}
```

### Step 2 — Attack Side Selection (contropiede, fuorigioco)

```php
// Fuorigioco trap: chance to negate opponent's attack
if ($defTactics['fuorigioco'] > 0) {
    $offsideChance = (int)($defTactics['fuorigioco'] * 0.15);
    if (mt_rand(1, 100) <= $offsideChance) {
        return $events; // attack nullified by offside trap
    }
}

// Contropiede: fast break gives attack bonus
if ($tactics['contropiede'] > 0 && $isCounterAttack) {
    $atkForce *= (1 + $tactics['contropiede'] / 100 * 0.15);
}
```

### Step 3 — Attack vs Defence (palla_bassa, catenaccio)

```php
$defForce = $def['df'] + (int)($def['cn'] * 0.3);
$defForce *= (1 + $defTactics['catenaccio'] / 100 * 0.12);

$atkForce = $atk['at_' . $side] + (int)($atk['cr'] * 0.3);
$atkForce *= (1 - $defTactics['palla_bassa'] / 100 * 0.05);
```

### Step 5 — Precision Gate (calci_piazzati)

```php
// If event originated from a set piece (detected by zone proximity to penalty spot):
$precisionCap = 30 + (int)($tactics['calci_piazzati'] * 0.20);
if (mt_rand(1, 100) <= $precisionCap) {
    // GOAL
}
```

## Tactic Conflicts & Mutual Exclusion

Some tactics conflict — high values in both weakens both:

| Conflict pair | Penalty when both >50 |
|---------------|----------------------|
| Pressing + Catenaccio | Pressing −30% effective |
| Lancio lungo + Possesso palla | Possesso −40% effective |
| Fuorigioco + Catenaccio | No penalty (defensive stack allowed) |

## Live Tactical Adjustment (manager during match)

Via existing `MatchCommand` (SIP-0023), the manager can switch between 3 presets:

| Preset | Pressing | Possesso | Catenaccio | Contropiede |
|--------|---------|---------|-----------|------------|
| **Difensivo** | 20% | 30% | 70% | 60% |
| **Bilanciato** | 50% | 50% | 30% | 30% |
| **Offensivo** | 80% | 70% | 10% | 20% |

Applied immediately by `MatchEngine::applyPendingActions()`.
