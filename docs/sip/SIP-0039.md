## Summary

Define the complete weekly training cycle that integrates:
1. **Physical training** — individual skill growth (see [[SIP-0036]] Part A)
2. **Tactical training** — team tactical levels (see [[SIP-0036]] Part B)
3. **Staff amplification** — better staff → faster and higher quality results
4. **Fatigue management** — heavy training reduces freshness; light training recovers it
5. **Training focus vs. match schedule** — training load must be managed around match weeks

---

## Weekly Training Cycle

Runs each Monday via `EconomyController::actionRunCron()`.

```
Monday 00:00
  ├── applySkillTraining()     → update player stats based on alloc_* sliders
  ├── applyTacticTraining()    → update training_tactic levels
  ├── applyFatigueEffects()    → adjust freshness/condition
  ├── applyStaffBonuses()      → apply efficiency multipliers
  └── applyRecovery()          → doctor heals injured players
```

## Physical vs Tactical Balance

The manager splits 100 total training points per week.

### Allocation modes

| Mode | Physical | Tactical | Effect |
|------|---------|---------|--------|
| Full Physical | 80-100 | 0-20 | Fast skill growth, tactics stagnate |
| Balanced | 50 | 50 | Steady growth on both dimensions |
| Full Tactical | 0-20 | 80-100 | Tactics improve fast, skills plateau |
| Recovery | 10 | 10 | Low load: freshness recovers +5/week |

### Freshness Impact

```php
$total_load = $physical_points + $tactical_points;
$freshness_delta = match(true) {
    $total_load >= 80 => -3,    // heavy week: freshness −3
    $total_load >= 50 => -1,    // moderate: freshness −1
    $total_load >= 20 => +2,    // light: freshness +2
    default            => +5,   // rest week: freshness +5
};
// Capped at [0, 100]
```

### Condition Impact

```php
// Diligente character: trains harder → extra condition decay
if ($player->character === 'diligente') {
    $freshness_delta -= 2;
}
// Preparatore Atletico (fitness coach) mitigates:
$freshness_delta += min(0, $fitness_coach_efficiency / 50); // max +2
```

## Staff Amplification

Applied on top of the base XP formula from [[SIP-0036]]:

```
Final XP = base_xp × age_mod × character_mod × staff_mod

Where staff_mod:
  Physical training:  1 + (assistant_efficiency × 0.05 / 100)
  GK skills only:     1 + (gk_coach_efficiency  × 0.15 / 100)
  Tactical training:  1 + (head_coach_efficiency × 0.10 / 100)
  Recovery:           1 + (doctor_efficiency     × 1.00 / 100) [injury only]
```

### Concrete Example

- Head coach efficiency: 80
- Vice efficiency: 60
- Fitness coach: 70
- Player: 26 years old, character "diligente"

```
Tactical XP bonus:  +8.0%  (head coach 80 × 0.10%)
Physical XP bonus:  +3.0%  (assistant 60 × 0.05%)
Diligente modifier: +15%
Age modifier (26):  -2%
Total multiplier:   1.08 × 1.03 × 1.15 × 0.98 ≈ 1.25×
```
→ Player gains 25% more XP than an uncoached average-age player.

## Match Week Penalty

On a match week (fixture within 3 days), heavy training reduces performance:

```php
if ($matchThisWeek && $total_load > 60) {
    $form_penalty = ($total_load - 60) * 0.1;
    $player->form = max(0, $player->form - $form_penalty);
}
```

This forces the manager to choose between peaking players for the match
or pushing hard on long-term development.

## Training History & Progression Charts

Store weekly snapshots in `training_log` table:

```sql
CREATE TABLE training_log (
  id          INT AUTO_INCREMENT PRIMARY KEY,
  team_id     INT NOT NULL,
  player_id   INT NOT NULL,
  week        TINYINT NOT NULL,
  season      INT NOT NULL,
  stat        VARCHAR(20) NOT NULL,
  xp_gained   FLOAT NOT NULL,
  new_value   TINYINT NOT NULL,
  created_at  INT NOT NULL
);
```

Used to show progression charts in the player detail view (SIP-0032 extension).
