# SIP-0034 — Italian Name Database (Legacy Import)

| Field   | Value                 |
|---------|-----------------------|
| Status  | Accepted (Implemented)     |
| Author  | Gold Manager Dev Team |
| Created | 2026-05-18            |

## Summary

Replace the current `WorldData::FIRST_NAMES` and `WorldData::LAST_NAMES` arrays
(~100 names, ~120 surnames) with the full Italian name database recovered from the
legacy GU Classic / Gold Manager project.

Source files:
- `newGM/appoggio/nomi e cognomi/nomi propri.csv` — **1 044 first names**
- `newGM/appoggio/nomi e cognomi/nuovo_cognomi.csv` — cleaned surname export used by the v2 importer

This gives ~1.9 million unique name combinations, virtually eliminating
collision probability in large worlds.

---

## Source File Format

### `nomi propri.csv`
```
0;Abaco
0;Abbondanzio
1;Adriano
...
```
Field 0: gender flag (0 = male, currently all players are male)
Field 1: name

### `nuovo_cognomi.csv`
```
0;Ridurre
0;Abbattista
0;Accardo
...
```
Field 0: legacy flag, ignored by importer
Field 1: surname

## Implementation

### Step 1: ETL script

Create `v2/commands/ImportNamesController.php`:

```bash
./yii import-names/run
```

This command:
1. Reads both CSV files
2. Cleans duplicates and invalid entries (e.g., `"Adamo Adamo"` → `"Adamo"`)
3. Inserts into two new DB tables:

```sql
CREATE TABLE name_first (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(60) NOT NULL,
    gender TINYINT NOT NULL DEFAULT 0
);

CREATE TABLE name_last (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(60) NOT NULL
);
```

### Step 2: WorldData update

Change `WorldData::FIRST_NAMES` and `WorldData::LAST_NAMES` from static PHP arrays
to DB queries:

```php
public static function randomFirstName(): string
{
    return Yii::$app->db->createCommand(
        'SELECT name FROM {{%name_first}} ORDER BY RAND() LIMIT 1'
    )->queryScalar() ?: 'Marco';
}

public static function randomLastName(): string
{
    return Yii::$app->db->createCommand(
        'SELECT name FROM {{%name_last}} ORDER BY RAND() LIMIT 1'
    )->queryScalar() ?: 'Rossi';
}
```

### Step 3: PlayerSeeder update

`PlayerSeeder::uniqueName()` uses `WorldData::randomFirstName()` +
`WorldData::randomLastName()` instead of array_rand on the static arrays.

### Step 4: WorldData static arrays

Keep the static arrays as fallback (for tests and offline environments).
The DB method is tried first; if DB unavailable, falls back to array.

---

## Cleaning Rules

Applied during import:
1. Trim whitespace
2. Title-case (e.g., `ABBATTISTA` → `Abbattista`)
3. Remove duplicates (case-insensitive)
4. Remove entries with embedded spaces that repeat the word (e.g., `"Adamo Adamo"` → `"Adamo"`)
5. Minimum length: 2 characters
6. Maximum length: 60 characters

Current clean count:
- First names: 1,043 unique (after dedup; `Valter` is duplicated in source)
- Surnames: 1,849 unique from `nuovo_cognomi.csv`
