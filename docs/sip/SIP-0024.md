## Summary

Port the legacy character trait logic and the half-time pause mechanism to the high-performance Go worker. This ensures that match results are not just based on raw skills but also on player personality and tactical pacing.

## Technical Details

### 1. Character Traits in Go
Implement the `engine/character.go` module to apply modifiers during the action resolution:
- **Grintoso**: +10% bonus to duels if the team is losing.
- **Carismatico**: +5% bonus to all teammates if this player is on the pitch.
- **Introverso**: -5% penalty to pass success if playing away.
- **Irrequieto**: +20% chance of yellow/red card but +10% to physical duels.

### 2. Half-time Pause Logic
The Go scheduler currently advances one minute per real-time second (or as configured). 
- When `current_minute == 45`, the worker must enter a `PAUSED_HALF_TIME` state.
- The pause lasts for 15 seconds (configurable via ENV).
- A specific `match_event` (Half-time whistle) is broadcast via SSE.
- This gives managers a dedicated window for tactical changes before the second half begins.

### 3. Injury Logic
Introduce a random injury generator based on:
- Player `condition`.
- Match `intensity` (from training settings).
- Luck.
- Injuries force an immediate substitution (AI picks the best sub if human is not online).

## Acceptance Criteria
- [ ] Go engine applies at least 3 distinct character trait modifiers.
- [ ] Live matches pause at the 45th minute for a visual "Half-time" break.
- [ ] Injuries can occur and are recorded in `match_event`.
