# SIP-0024 — Advanced Match Logic: Character Traits & Half-time

| Field   | Value                  |
|---------|------------------------|
| Status  | Accepted (Implemented) |
| Created | 2026-05-16             |

## Summary

Port the legacy character trait logic and the half-time pause mechanism to the Go worker.
PHP and Go engines kept in parity (Go-parity rule).

## Technical Details

### 1. Character Traits (PHP + Go parity)

| Trait          | Effect                                              |
|----------------|-----------------------------------------------------|
| `grintoso`     | +10% when losing                                    |
| `ambizioso`    | +5% always                                          |
| `introverso`   | −5% when away                                       |
| `razionale`    | +5% when away                                       |
| `irrequieto`   | +10% home / −5% away                                |
| `egoista`      | +8% home / −3% away; +12% card risk                 |
| `fantasioso`   | +10% or −5% randomly per tick (65/35)               |
| `inflessibile` | +10% in position / −15% out (PHP); +3% avg (Go)     |
| `duttile`      | +5% out of position (PHP); +1% avg (Go)             |
| `diligente`    | condition×1.05 / freshness×0.90; −10% injury risk   |
| `costante`     | Narrower form variance; −5% injury risk             |
| `carismatico`  | Team-level: +1% bonus, morale flag                  |
| `corretto`     | −30% card risk                                      |
| `popolare`     | +2% morale                                          |

### 2. Half-time Mechanics

- Pause: 15 ticks (configurable via `GM_HALF_TIME_TICKS`).
- **Morale boost:** trailing team gets +5% totals boost for the entire second half.
  Applied in both PHP (`MatchEngine::advanceTick`) and Go (tick loop, `phase == SECOND_HALF`).

### 3. Injury Logic

- Player `condition` and luck determine injury probability.
- `diligente` lowers injury scalar; `irrequieto` raises discipline scalar.
