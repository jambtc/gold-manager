# SIP-0043 — Live Substitution UI

| Field   | Value                 |
|---------|-----------------------|
| Status  | Deferred (Backlog)         |
| Author  | Gold Manager Dev Team |
| Created | 2026-05-19            |

## Summary

Allow the manager to make substitutions during a live match via the Panchina panel.
The substitution is queued in `MatchState.pending_{side}_actions` and processed by
`MatchEngine::applyPendingActions()` at the next tick.

Backend (`LiveActionController::actionSubstitution`) already exists and writes to
`MatchCommand` (Go engine) and to `MatchState` (PHP engine, via this SIP fix).
This SIP covers **only the frontend UI** missing in the Panchina panel.

---

## Rules

| Rule | Value |
|------|-------|
| Max substitutions per match | 5 |
| Window | From minute 1 to minute 89 (not during half-time ticks) |
| Restriction | Cannot substitute an already-substituted player |
| Effect | Swap player in active formation slot next tick |
| Friendly | Substitutions count the same |

---

## UI Design — Panchina Panel

The Panchina panel (right column in `/fixture/live`) currently shows:
- Formation starters count (X/11)
- Three tactic preset buttons (Difensivo / Bilanciato / Offensivo)

Add below the tactic buttons:

```
── Sostituzioni ──────────────────────────────
Cambi effettuati: 1/5

[Effettua sostituzione ↔]   ← button opens modal

(if 5 subs used: button disabled "Cambi esauriti")
```

---

## Modal — Sostituzione

Triggered by clicking "Effettua sostituzione ↔". Shows two lists side by side:

```
┌─────────────────────────────────────────────────────────┐
│  Sostituzione                                   ✕       │
│                                                         │
│  TITOLARI IN CAMPO        PANCHINA DISPONIBILE          │
│  ┌─────────────────┐      ┌──────────────────────────┐  │
│  │ [PO] Brambilla  │      │ [GK] Ferretti         62 │  │
│  │       skill 52  │      │ [DF] Gallo             58 │  │
│  │ [DF] Rossi ★   │      │ [MF] Palmieri         65 │  │
│  │       skill 61  │  →   │ [FW] Cavalli          70 │  │
│  │ [MF] Bianchi    │      └──────────────────────────┘  │
│  │       skill 58  │                                     │
│  └─────────────────┘                                     │
│                                                         │
│  Seleziona chi ESCE (sx) e chi ENTRA (dx)               │
│                                                         │
│  [Annulla]                [✓ Conferma sostituzione]     │
└─────────────────────────────────────────────────────────┘
```

**Interaction:**
1. Click a player in the "Titolari" list → highlighted as "uscente"
2. Click a player in the "Panchina" list → highlighted as "entrante"
3. Both selected → "Conferma" button enabled
4. Click "Conferma" → POST to `/live-action/substitution`
5. Flash message: "✓ {out} → {in} prenotato per il prossimo tick"
6. Sub counter updates: `1/5 → 2/5`
7. inserisci la sostituzione nel pannello degli score

## Data Source

When the modal opens, fetch via AJAX:

```
GET /live-action/roster?fixtureId={id}
```

Returns:

```json
{
  "starters": [
    { "id": 12, "name": "Marco Brambilla", "position": "GK", "skill": 52 },
    ...
  ],
  "bench": [
    { "id": 7, "name": "Luigi Ferretti", "position": "GK", "skill": 62 },
    ...
  ],
  "subs_used": 1,
  "max_subs": 5
}
```

`starters` = players in active FormationSlot for the team.
`bench` = players on the team NOT in formation, excluding already-substituted players.

New action: `LiveActionController::actionRoster(int $fixtureId)`.

## Backend Fix (same as tactic fix — SIP-0043 implementation)

`LiveActionController::actionSubstitution` must ALSO write to
`MatchState.pending_{side}_actions` (currently only writes to `MatchCommand`):

```php
// After existing MatchCommand save:
$state = MatchState::findOne(['fixture_id' => $fixtureId]);
if ($state) {
    $field = "pending_{$side}_actions";
    $actions = json_decode($state->$field ?? '[]', true) ?: [];
    $actions[] = ['type' => 'substitution', 'out' => $playerOutId, 'in' => $playerInId];
    $state->$field = json_encode($actions);
    $state->save(false);
}
```

## Visual Feedback in Live Commentary

When the substitution tick fires, the existing `substitution` event type already appears
in the live view with icon 🔄:

```
47' 🔄  [🛡️ Corsa Calcio]  SUBSTITUTION
         "Cambio in campo! Entra Ferretti al posto di Brambilla."
```

The Panchina panel also updates:
- The subbed-off player grays out in the starters list
- `subs_used` counter increments

---

## Half-time Special Case

During `phase === 'half_time'` (15 ticks), substitutions CAN be queued but are
processed on the `second_half_start` tick. This is shown to the user:

```
🔔 INTERVALLO — Puoi effettuare sostituzioni ora.
               Saranno eseguite all'inizio del secondo tempo.
```
