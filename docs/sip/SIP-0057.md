# SIP-0057 — Scouting System

| Field   | Value                 |
|---------|-----------------------|
| Status  | Accepted (Implemented) |

## Summary

The manager can send the club's scout to observe a specific player.
After a configurable delay (based on scout efficiency), a `scouting_report`
arrives in the news feed with partial or complete player stats.
Report accuracy scales with scout efficiency: a weak scout reveals blurry data,
a top scout reveals exact values.

Scouting is the primary way to discover free agents and players on rival teams
before making a transfer offer.

---

## Scout Role (from SIP-0046)

The scout is hired from `staff_market` with `role = 'scout'`.
`efficiency` (0–100) drives two things:
- **Duration**: `ceil(7 - efficiency / 20)` days (5 days at eff=0, 1 day at eff=100)
- **Accuracy**: stats revealed with ±N% noise (lower noise at higher efficiency)

| Efficiency | Days to report | Stat accuracy |
|-----------|----------------|---------------|
| 0–19      | 5 days         | ±30% noise    |
| 20–39     | 4 days         | ±20% noise    |
| 40–59     | 3 days         | ±15% noise    |
| 60–79     | 2 days         | ±10% noise    |
| 80–100    | 1 day          | ±5% noise     |

Without a scout on staff: scouting is disabled.

## Flow

```
Manager clicks [Osserva] on a player card
→ POST /scouting/scout {player_id}
→ Check: team has a scout on staff
→ Check: no pending report for same player by same team
→ Create scouting_report(status=pending, ready_at=now+delay, scout_eff=scout.efficiency)
→ Flash: "Marco Rossi sotto osservazione. Rapporto in N giorni."

Cron (run-fixtures or daily at midnight):
→ ScoutingService::processReadyReports()
→ For each report where status=pending AND ready_at <= now():
   → Fetch player real stats
   → Apply noise based on scout_eff
   → Save obfuscated data to report_text (JSON)
   → Set status=ready
   → NewsService::create(CAT_TRANSFER, '🔍', "Rapporto scout: {player}", ...)
```

## Report Content (obfuscated JSON)

```json
{
  "name":          "Marco Rossi",
  "age":           24,
  "position":      "MF",
  "foot":          "R",
  "general_skill": 68,
  "skill_po":  "~10",
  "skill_df":  "~45",
  "skill_cn":  "~72",
  "skill_pa":  "~68",
  "skill_rg":  "~55",
  "skill_cr":  "~30",
  "skill_tc":  "~60",
  "skill_tr":  "~58",
  "potential_score": 72,
  "note": "Buon centrocampista con ottima visione di gioco."
}
```

The `~` prefix indicates approximate values. At high scout efficiency the values
are exact (no `~`). At low efficiency values are rounded to nearest 5 or 10.

`potential_score` is always shown as the scout's assessment (may differ from
`general_skill` if the player has high `experience` relative to skills).

## ScoutingService

```php
class ScoutingService
{
    public static function canScout(int $teamId): bool
    {
        return Staff::find()
            ->where(['team_id' => $teamId, 'role' => Staff::ROLE_SCOUT])
            ->exists();
    }

    public static function queueReport(int $teamId, int $playerId): ScoutingReport
    {
        $scout = Staff::findOne(['team_id' => $teamId, 'role' => Staff::ROLE_SCOUT]);
        $eff   = $scout ? (int) $scout->efficiency : 50;
        $days  = (int) ceil(7 - $eff / 20);  // 1–5 days

        $report = new ScoutingReport();
        $report->team_id    = $teamId;
        $report->player_id  = $playerId;
        $report->status     = 'pending';
        $report->scout_eff  = $eff;
        $report->ready_at   = time() + $days * 86400;
        $report->save(false);
        return $report;
    }

    public static function processReadyReports(): int
    {
        $reports = ScoutingReport::find()
            ->where(['status' => 'pending'])
            ->andWhere(['<=', 'ready_at', time()])
            ->all();

        foreach ($reports as $report) {
            $player = Player::findOne($report->player_id);
            if (!$player) { $report->delete(); continue; }

            $noise = (int) round(30 - $report->scout_eff * 0.25); // 5–30%
            $data  = self::obfuscate($player, $noise);
            $report->report_text = json_encode($data, JSON_UNESCAPED_UNICODE);
            $report->potential_score = $data['potential_score'];
            $report->status = 'ready';
            $report->save(false);

            $team = Team::findOne($report->team_id);
            if ($team?->user_id) {
                NewsService::create(
                    (int) $team->user_id,
                    NewsItem::CAT_TRANSFER,
                    '🔍',
                    "Rapporto scout: {$player->name}",
                    "Skill stimata {$data['general_skill']} — {$player->position}, {$player->age} anni",
                    Yii::$app->urlManager->createUrl(['/scouting/report', 'id' => $report->id])
                );
            }
        }
        return count($reports);
    }

    private static function obfuscate(Player $player, int $noise): array
    {
        $fuzz = fn(int $v) => max(1, min(99, $v + mt_rand(-$noise, $noise)));
        $exact = $noise <= 5;
        $fmt   = fn(int $v) => $exact ? $v : '~' . (int) round($fuzz($v) / 5) * 5;

        return [
            'name'          => $player->name,
            'age'           => $player->age,
            'position'      => $player->position,
            'foot'          => $player->foot,
            'general_skill' => $fuzz($player->general_skill),
            'skill_po'      => $fmt($player->skill_po),
            'skill_df'      => $fmt($player->skill_df),
            'skill_cn'      => $fmt($player->skill_cn),
            'skill_pa'      => $fmt($player->skill_pa),
            'skill_rg'      => $fmt($player->skill_rg),
            'skill_cr'      => $fmt($player->skill_cr),
            'skill_tc'      => $fmt($player->skill_tc),
            'skill_tr'      => $fmt($player->skill_tr),
            'potential_score' => $fuzz($player->general_skill),
            'note'          => self::generateNote($player, $noise),
        ];
    }

    private static function generateNote(Player $player, int $noise): string
    {
        $adj = match(true) {
            $player->general_skill >= 75 => 'eccellente',
            $player->general_skill >= 60 => 'buono',
            $player->general_skill >= 45 => 'discreto',
            default                       => 'modesto',
        };
        if ($noise > 20) {
            return "Giocatore " . $adj . " per la categoria. Difficile valutare con precisione.";
        }
        return "Giocatore {$adj}. " . ucfirst($player->character ?? '') . ". Valutazione attendibile.";
    }
}
```

## UI

### `/scouting/index` — Lista rapporti

Three sections:
1. **In attesa** — pending reports with countdown
2. **Pronti** — completed reports to review
3. **Archiviati** — dismissed reports

### `/scouting/report?id=X` — Dettaglio rapporto

Shows the obfuscated player card with `~` values styled in amber.
Button: **[Fai un'offerta]** → links to transfer market or direct offer if listed.

### [Osserva] button placement

- `transfer/market` player card — button next to existing detail link
- `player/view` — button in "Acquisto" panel if not already scouted
- `team/view` opponent modal (future)

## Cron integration (SIP-0055)

Add to `docker/cron-entry.sh`:

```bash
register_job \
    "${CRON_ENABLE_SCOUTING:-1}" \
    "${CRON_SCOUTING_SCHEDULE:-*/30 * * * *}" \
    "php yii scouting/process" \
    "$LOGS/scouting.log" \
    "scouting"
```

Runs every 30 minutes. Console command: `scouting/process`.
