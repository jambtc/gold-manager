# SIP-0060 — Live Formation Display (Both Teams)

## Summary

During a live match the manager can switch to a **Formazioni** tab that shows
both teams' current lineups on a miniature pitch side-by-side, with jersey
numbers, player names, position, and live substitution tracking.
Mirrors the GU Classic layout (reference screenshot).

## Data Sources

### My team formation
- `MatchState.home_formation_id` / `away_formation_id`
- `FormationSlot[]` — zone → player_id → jersey + name + position
- Substitutions tracked via `match_event.type = 'substitution'`

### Opponent formation
- Same approach (both formations are in MatchState)
- For the manager: opponent slots visible (name + number, no stats)
- For admin: full view of both formations

---

## Miniature Pitch Renderer

Each team's formation is rendered on a `<canvas>` or SVG miniature (250×350px):

- Pitch: green with white lines (simplified: center circle, penalty areas)
- Players: colored circle (home = home team color, away = away color)
- Number: inside circle (font-size tiny)
- Name: below circle, truncated to 8 chars
- Captain badge: 🛡 overlay
- Substituted off: circle grayed out + ↕ icon
- Injured/red card: circle red-outlined

### Zone → Pitch Coordinates

The existing 9×7 grid (63 zones) maps to pitch coordinates:

```javascript
function zoneToXY(zone, side) {
    var col = (zone - 1) % 7;   // 0-6
    var row = Math.floor((zone - 1) / 7); // 0-8
    var x = (col + 0.5) / 7;    // 0..1
    var y = side === 'home'
        ? 1 - (row + 0.5) / 9   // home attacks upward
        : (row + 0.5) / 9;      // away attacks downward
    return { x: x * pitchW, y: y * pitchH };
}
```

## Module Detection

Parse the formation name for the module string (e.g. "4-4-2"):

```javascript
var m = formation.name.match(/(\d-\d-\d(?:-\d)?)/);
var module = m ? m[1] : '?';
```

## Live Updates

The formation tab refreshes on every SSE event of type `substitution`:
- Move jersey from original zone to "bench" position (grayed)
- Add incoming player jersey to the zone

Events already in `eventQueue` — when `type === 'substitution'` is processed,
the formation renderer is called to update positions.

## Implementation

### New tab in `live.php`

```html
<ul class="nav nav-tabs">
  <li><button data-target="#tab-cronaca">Cronaca</button></li>
  <li><button data-target="#tab-formazioni">Formazioni</button></li>
  <li><button data-target="#tab-classifica">Classifica</button></li>
</ul>
```

### API endpoint

```
GET /fixture/formations?fixtureId=X
```

Returns JSON with both teams' slots + module + substitutions made:

```json
{
  "home": {
    "module": "3-4-3",
    "color_left": "#f97316",
    "color_right": "#f97316",
    "players": [
      { "zone": 5, "player_id": 101, "name": "Pagliuca", "number": 21,
        "position": "GK", "subbed_off": false }
    ]
  },
  "away": { ... }
}
```

### JS renderer

```javascript
function renderFormation(ctx, teamData, side) {
    teamData.players.forEach(function(p) {
        var pos = zoneToXY(p.zone, side);
        drawJersey(ctx, pos.x, pos.y, p.number, p.color, p.subbed_off);
        drawName(ctx, pos.x, pos.y + 18, p.name.substring(0, 8));
    });
}
```
