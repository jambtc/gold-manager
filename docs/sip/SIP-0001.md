# SIP-0001: SIP Process and Governance

- Status: Accepted (Implemented)
- Type: Process
- Created: 2026-05-14

## Abstract

This SIP defines the governance model for Gold Manager v2.

## Motivation

The original project evolved organically without a formal improvement process. Gold Manager v2 introduces structured technical governance.

## Specification

Every architectural or gameplay-impacting change should be described in a SIP.

Each SIP must contain:

- Abstract
- Motivation
- Specification
- Backward compatibility
- Security considerations
- Migration considerations

## SIP lifecycle

- Draft
- Review
- Accepted
- Implemented
- Deprecated
- Rejected

## Numbering

SIPs use sequential numbering.

Example:

- SIP-0001
- SIP-0002
- SIP-0100

## Responsibilities

Maintainers are responsible for:

- Reviewing SIPs
- Approving architecture changes
- Preventing undocumented breaking changes
