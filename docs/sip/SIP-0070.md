# SIP-0070: Player Nationality & Multi-National Name Database

- Status: Accepted (Implemented)
- Type: Data / Feature
- Created: 2026-05-27
- Supersedes: SIP-0034 (Italian Name Database — extends and replaces)

## Abstract

Add a `nationality` field to `player` and extend the name tables (`name_first`,
`name_last`) with a `nationality` column. Populate with names from multiple
nations. The `WorldData::FIRST_NAMES` / `LAST_NAMES` static arrays become
dead code and are removed once the DB tables are populated.

## Motivation

- All generated players are Italian — no variety in world simulation.
- `WorldData.php` is a maintenance liability: names are hardcoded, not editable.
- SIP-0034 added `name_first`/`name_last` tables but without nationality — still
  Italy-only.
- Player nationality will be needed for future national-team or transfer market
  features.

## Specification

### 1. Player table — add `nationality`

Migration: add `nationality VARCHAR(3) NOT NULL DEFAULT 'ITA'` (ISO 3166-1 alpha-3)
to the `player` table.

```sql
ALTER TABLE player ADD COLUMN nationality VARCHAR(3) NOT NULL DEFAULT 'ITA'
    AFTER position;
```

### 2. Extend name tables — add `nationality`

Migration: add `nationality VARCHAR(3) NOT NULL DEFAULT 'ITA'` to both
`name_first` and `name_last`. Drop the UNIQUE constraint on `name_last.name`
(same surname can exist in multiple nationalities).

```sql
ALTER TABLE name_first ADD COLUMN nationality VARCHAR(3) NOT NULL DEFAULT 'ITA';
ALTER TABLE name_last  ADD COLUMN nationality VARCHAR(3) NOT NULL DEFAULT 'ITA';
ALTER TABLE name_last  DROP INDEX name; -- remove unique constraint
```

Add indexes:
```sql
CREATE INDEX idx_nf_nationality ON name_first (nationality);
CREATE INDEX idx_nl_nationality ON name_last  (nationality);
```

### 3. Seed name data

Populate `name_first` and `name_last` with names grouped by nationality.
Initial target nations (extendable):

| Code | Nation      |
|------|-------------|
| ITA  | Italy       |
| ESP  | Spain       |
| BRA  | Brazil      |
| ARG  | Argentina   |
| FRA  | France      |
| DEU  | Germany     |
| ENG  | England     |
| PRT  | Portugal    |
| NLD  | Netherlands |
| HRV  | Croatia     |

Seeder script or migration inserts ~50 first names + ~50 last names per nation.

### 4. WorldSeeder — nationality-aware generation

`PlayerSeeder::buildAttributes()` receives (or randomly picks) a nationality.
Names are drawn filtered by nationality:

```php
$nationality = $this->pickNationality();  // weighted random (e.g. 40% ITA, 10% each other)
$firstName   = WorldData::randomFirstName($nationality);
$lastName    = WorldData::randomLastName($nationality);
```

`WorldData::randomFirstName(string $nationality)` queries:
```sql
SELECT name FROM name_first WHERE nationality = :n ORDER BY RAND() LIMIT 1
```

Falls back to static array if table is empty.

### 5. Remove WorldData static arrays

Once name tables are populated and seeder uses DB:
- Remove `FIRST_NAMES` and `LAST_NAMES` constants from `WorldData`.
- Keep `TEAM_NAMES`, `CHARACTERS`, `statProfile`, `ageRange`, `rosterComposition`.

### 6. Display — SVG nationality flag

Show the flag inline in `player/view` (hero section, next to position badge) and
as a small icon in `team/view` player rows.

**Source:** [flagcdn.com](https://flagcdn.com) — free, no key required.
URL pattern: `https://flagcdn.com/w40/{cc}.svg` where `{cc}` is the ISO 3166-1
**alpha-2** code (2-letter, lowercase).

Add a helper map ISO alpha-3 → alpha-2 in `UiIconHelper` (or a dedicated
`NationalityHelper`):

```php
private const FLAG_CODE = [
    'ITA' => 'it', 'ESP' => 'es', 'BRA' => 'br', 'ARG' => 'ar',
    'FRA' => 'fr', 'DEU' => 'de', 'ENG' => 'gb-eng', 'PRT' => 'pt',
    'NLD' => 'nl', 'HRV' => 'hr',
];

public static function flagImg(string $nationality, int $width = 20): string
{
    $cc = self::FLAG_CODE[$nationality] ?? strtolower(substr($nationality, 0, 2));
    $url = 'https://flagcdn.com/w40/' . $cc . '.svg';
    return '<img src="' . Html::encode($url) . '" width="' . $width . '"'
         . ' alt="' . Html::encode($nationality) . '"'
         . ' style="border-radius:2px;vertical-align:middle;box-shadow:0 0 0 1px rgba(255,255,255,.15)">';
}
```

**player/view hero** — next to position badge:

```php
<?= UiIconHelper::flagImg($player->nationality, 22) ?>
```

**team/view row** — 16px, before the player name:

```php
<?= UiIconHelper::flagImg($player->nationality, 16) ?>
```

Fallback: if `nationality` is empty or unknown, render nothing (no broken image).

## Migrations

1. `mXXXXXX_add_nationality_to_player` — alter player table
2. `mXXXXXX_add_nationality_to_name_tables` — alter name_first / name_last
3. `mXXXXXX_seed_names_multinational` — insert name data per nationality

## Acceptance Criteria

- `player.nationality` is set for all generated players.
- Name draw is filtered by nationality — no Spanish names for Italian players.
- `WorldData::FIRST_NAMES` and `LAST_NAMES` constants are deleted.
- `WorldData::randomFirstName()` and `randomLastName()` accept a `$nationality` param.
- Fallback to static array still works if DB table is empty (backwards compatibility
  during migration window).

## Effort Estimate

Medium — migrations are simple; bulk of work is sourcing and inserting name data
per nationality and updating `PlayerSeeder`.
