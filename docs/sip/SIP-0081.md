## Obiettivo

Inviare ogni mattina (ora configurabile, default 08:00) un riepilogo testuale
al manager che riassume la situazione della squadra nelle ultime 24 ore e
nella stagione corrente.

Il digest copre tre aree:

1. **Squadra** — forma media, freschezza media, infortuni attivi, squalifiche
2. **Finanziario** — budget corrente, stipendi settimanali, bilancio stagionale
3. **Statistiche giocatori** — top crescita e top calo nelle ultime 24 h

---

## Architettura proposta

### Flusso

```
EconomyController::actionSendDailyDigest()
  ↓
  per ogni team con manager umano:
    DigestBuilder::build(team) → DigestPayload
    NotificationService::notify(userId, CAT_SYSTEM, ..., telegramText)
  ↓
  notification/dispatch (già esistente) → Telegram
```

### DigestPayload

```php
class DigestPayload {
    string $title;        // "📊 Morning Report — FC Napoli"
    string $body;         // testo multi-riga in-app
    string $telegramText; // stesso testo compatto per Telegram
}
```

### DigestBuilder

```php
final class DigestBuilder
{
    public static function build(Team $team): DigestPayload
    {
        // 1. Player status
        $players       = Player::find()->where(['team_id' => $team->id])->all();
        $avgForm       = avg($players, 'form');
        $avgFreshness  = avg($players, 'freshness');
        $injured       = count(array_filter($players, fn($p) => $p->injury_weeks > 0));
        $suspended     = count(array_filter($players, fn($p) => $p->suspended_matches > 0));

        // 2. Top movers (24h snapshot)
        // Compare player.form/skill stats vs snapshot_player_stats (da SIP-0054 daily snapshot)
        // top 3 crescita e top 3 calo per general_skill_delta_1d

        // 3. Finance
        $budget       = $team->budget;
        $weeklyWages  = sum(Contract::active for team);
        $seasonBalance = sum(Transfer.fee_received - Transfer.fee_paid this season)
                        + sum(TeamSponsor.payments this season)
                        - sum(Contract.salary_paid this season);

        return new DigestPayload(...);
    }
}
```

### Snapshot

Usa la tabella `player_stat_snapshot` già presente (SIP-0054).  
Confronto: snapshot di ieri vs snapshot di oggi → delta per campo.

## Contenuto del digest

### In-app (body)

```
📊 Morning Report — {team_name}

⚽ Squadra
  Forma media:      {avgForm}%
  Freschezza media: {avgFreshness}%
  Infortuni:        {injured} giocatori
  Squalifiche:      {suspended} giocatori

💰 Finanze
  Budget:           €{budget}
  Stipendi/sett:    €{weeklyWages}
  Bilancio stagione: €{seasonBalance}

📈 Top crescita (24h)
  {player1}  +{delta1}
  {player2}  +{delta2}
  {player3}  +{delta3}

📉 Top calo (24h)
  {player4}  {delta4}
  {player5}  {delta5}
```

### Telegram

Versione compatta HTML (max ~300 char):

```
📊 <b>Morning Report</b> — {team_name}
⚽ Forma {avgForm}% · Freschi {avgFreshness}% · 🏥{injured} 🟥{suspended}
💰 Budget €{budget} · Stipendi €{weeklyWages}/sett
📈 {top1} +{d1} | 📉 {bot1} {d2}
```

## Acceptance criteria

- [ ] Ogni manager con squadra attiva riceve il digest ogni mattina alle 08:00
- [ ] Il digest contiene forma, freschezza, infortuni, squalifiche, budget
- [ ] Top 3 crescita / top 3 calo sono calcolati sul delta 24h da `player_stat_snapshot`
- [ ] Telegram viene inviato tramite `NotificationService` (asincrono, non bloccante)
- [ ] Se Telegram non è configurato, il digest appare comunque in-app (news badge)
- [ ] `DigestBuilder::build()` ha unit test con fixture di dati
