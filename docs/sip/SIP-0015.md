# SIP-0015: API Versioning

- Status: Draft
- Type: API
- Created: 2026-05-14

## Abstract

Define API versioning strategy.

## Specification

APIs SHALL use explicit versioning.

Example:

- /api/v1/
- /api/v2/

## Goals

- Backward compatibility
- Stable integrations
- Mobile support

## Deprecation policy

Deprecated APIs SHALL remain available during transition periods.
