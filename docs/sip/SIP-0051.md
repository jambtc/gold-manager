# SIP-0051 — CPU AI Behavior

| Field   | Value                 |
|---------|-----------------------|
| Status  | Implemented ✅             |
| Author  | Gold Manager Dev Team |
| Created | 2026-05-19            |

## Summary

CPU-managed teams participate in all game systems autonomously:
transfers, training, friendly challenges, match tactics and substitutions.
CPU behavior should be plausible (not optimal) — it creates a living world.

---

## Scope

| System | CPU behavior |
|--------|-------------|
| Transfer market | Buy needed players, sell surplus; respond to offers |
| Staff | Hire/fire based on budget; replace expired contracts |
| Training | Auto-set daily allocation based on weakest stats |
| Friendly | Accept/decline challenges; occasionally initiate |
| Match tactics | Choose preset based on league position |
| Substitutions | Auto-substitute tired/injured players at half-time |
| Formation | Use best available 11 (already implemented) |

## Part A — Transfer Market

### Trigger: Weekly scan (`EconomyController::runCpuTransferActivity()`)

```php
foreach (Team::find()->where(['is_cpu' => 1])->all() as $team) {
    $this->cpuBuyIfNeeded($team);
    $this->cpuSellSurplus($team);
    $this->cpuRespondToOffers($team);
}
```

### Buy Logic

CPU buys when:
- Roster < 18 players
- A position is critically weak (avg skill in dept < 45)
- Budget > salary_wage_bill × 4 (has surplus cash)

Price tolerance: up to `PlayerValuator::marketValue() × 1.1` (will pay slight premium).
Targets: free agents first (no fee), then cheapest market listing.

```php
function cpuBuyIfNeeded(Team $team): void {
    if (count($team->players) < 18 || $this->hasWeakDepartment($team)) {
        $target = PlayerPool::findBestFor($team); // free agent
        if (!$target && $team->budget > $team->totalWageBill() * 4) {
            $target = Transfer::cheapestOnMarket($neededPosition);
        }
        if ($target && $team->budget >= $target->asking_fee) {
            Transfer::complete($target, $team->id);
        }
    }
}
```

### Sell Logic

CPU sells when:
- Roster > 22 players
- Player skill < 35 AND player age > 30 (declining player)
- Budget critically low (< wage_bill × 2)

CPU lists players at `marketValue() × 0.9` (slight discount to sell quickly).

### Respond to Offers

CPU auto-accepts if: `offered_fee >= asking_fee × 0.85` (85% of asking).
CPU auto-rejects if: `offered_fee < marketValue() × 0.7`.

## Part C — Daily Training

CPU allocates training based on squad weaknesses:

```php
function cpuSetTraining(Team $team): array {
    // Compute average skill per category
    $avgStats = [
        'po' => avg([skill_po]), 'df' => avg([skill_df]),
        // etc.
    ];
    // Allocate more points to weaker stats
    // Each point = 100 / 10 stats = 10 base, +extra for weakness
    $allocation = [];
    foreach ($avgStats as $stat => $avg) {
        $weakness = max(0, 60 - $avg);  // how far below 60
        $allocation["alloc_$stat"] = 10 + (int)($weakness / 3);
    }
    // Normalize to 100
    return normalize($allocation, 100);
}
```

This is saved as a `training_day` record each morning (no UI needed for CPU).

## Part E — Match Tactics

CPU chooses tactic preset based on league position:

```php
function cpuChooseTactic(Team $team, int $currentRound): string {
    $standing = Standing::find(['team_id' => $team->id])->one();
    $position = $standing ? $standing->position : 8;

    if ($position <= 2) return 'balanced';      // top: maintain
    if ($position >= 14) return 'all_out_attack'; // bottom: desperate
    return mt_rand(0,1) ? 'balanced' : 'ultra_defensive'; // mid: varies
}
```

Live tactic changes: CPU may switch to `ultra_defensive` if winning by 2+ goals,
or `all_out_attack` if losing in the last 20 minutes.

```php
// In MatchEngine::applyPendingActions() — CPU auto-action every 10 ticks:
if ($isCpu && $min % 10 === 0) {
    $scoreDiff = $state->home_score - $state->away_score;
    if (($side==='home' && $scoreDiff >= 2) || ($side==='away' && $scoreDiff <= -2)) {
        // Switch to defensive when comfortably winning
        $this->queueTacticChange($fixture, $side, 'ultra_defensive', 'normal');
    } elseif ($min >= 70 && (
        ($side==='home' && $scoreDiff < 0) || ($side==='away' && $scoreDiff > 0)
    )) {
        // All out attack when losing late
        $this->queueTacticChange($fixture, $side, 'all_out_attack', 'normal');
    }
}
```

## Part F — Substitutions

CPU auto-substitutes at half-time and in the 60th/75th minute:

```php
function cpuAutoSubstitute(MatchState $state, string $side, int $minute): void {
    $subsUsed = $state->{"{$side}_subs_used"};
    if ($subsUsed >= 3) return;

    $formation = $state->{"{$side}Formation"};
    if (!$formation) return;

    // Find most tired starter (lowest freshness)
    $tiredest = null;
    foreach ($formation->slots as $slot) {
        $p = $slot->player;
        if (!$tiredest || $p->freshness < $tiredest->freshness) {
            $tiredest = $p;
        }
    }

    if ($tiredest && $tiredest->freshness < 60) {
        // Find best bench player for the position
        $sub = $this->findBestBench($state->team($side), $tiredest->position);
        if ($sub) {
            $this->queueSubstitution($fixture, $side, $tiredest->id, $sub->id);
        }
    }
}
```

Trigger times: half-time (minute 45), minute 60, minute 75.
CPU only substitutes if a starter has freshness < 60.
