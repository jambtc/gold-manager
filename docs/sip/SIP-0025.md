# SIP-0025 — Automatic League Expansion (Infinite World)

| Field   | Value                  |
|---------|------------------------|
| Status  | Accepted (Implemented) |
| Author  | Antigravity AI         |
| Created | 2026-05-16             |

## Summary

Resolve the "League is full" error by implementing a dynamic world expansion system.
When a new user registers and no free CPU teams are available, the system automatically
creates a new league tier or group.
Combined with SIP-0087 (Always-On Market), the engine never idles between seasons.

## Implementation

### 1. TeamAssigner (already in place)

`app\components\TeamAssigner::assign()`:

1. If the world is empty for a country → `WorldSeeder::run()`.
2. Find a free CPU team in any existing Serie C group for that country.
3. If none found → `expandSerieC()`: creates a new Serie C group via `WorldSeeder::seedLeague()`.
4. Claim the team: `is_cpu=0`, `user_id=$userId`.

### 2. Automatic Rollover — `actionAutoRollover`

`EconomyController::actionAutoRollover()`:

- Scans all `league` competitions.
- If a competition has 0 unfinished fixtures → calls `actionSeasonRollover()` automatically.
- Registered as cron job at `0 3 * * *`.
- Idempotent: safe to run multiple times.

### 3. Expansion Pool Pre-Seeding — `actionEnsureExpansionPool`

`EconomyController::actionEnsureExpansionPool(minFreeSlots = 4)`:

- For each country with a Serie C, counts free CPU slots.
- If below threshold → pre-seeds a new Serie C group before demand hits.
- Registered as cron job at `0 4 * * *`.

### 4. Always-On (SIP-0087)

`TransferWindowService::isOpen()` returns `true` by default (no seasonal windows).
Combined with automated rollover, there is no dead period between seasons.

## Cron Jobs

| Job                | Schedule      | Env flag                       |
|--------------------|---------------|--------------------------------|
| `auto-rollover`    | `0 3 * * *`   | `CRON_ENABLE_AUTO_ROLLOVER=1`  |
| `expansion-pool`   | `0 4 * * *`   | `CRON_ENABLE_EXPANSION_POOL=1` |

## Acceptance Criteria

- [x] Registration never fails with "League is full".
- [x] New competitions are correctly named and integrated into standings.
- [x] Fixtures for new leagues are generated immediately.
- [x] Seasons roll over automatically when all fixtures are played.
- [x] Free CPU slot pool is pre-seeded before it empties.
- [x] No manual intervention needed between seasons.
