# SIP-0025 — Automatic League Expansion (Infinite World)

| Field   | Value                     |
|---------|---------------------------|
| Status  | Accepted                  |
| Author  | Antigravity AI            |
| Created | 2026-05-16                |

## Summary

Resolve the "League is full" error by implementing a dynamic world expansion system. When a new user registers and no free CPU teams are available, the system automatically creates a new league tier or group.

## Implementation Plan

### 1. Tier & Group Logic
Update the `competition` table to support hierarchy:
- `tier`: 1 (Serie A), 2 (Serie B), 3 (Serie C)...
- `group`: 1, 2, 3... (for parallel leagues at the same tier).

### 2. TeamAssigner Logic
Modify `app\components\TeamAssigner::assign()`:
1. Try to find a team with `user_id IS NULL` and `is_cpu = 1`.
2. If none found:
    - Identify the lowest active tier.
    - Check if a group in that tier has space (< 16 teams).
    - If all groups are full, create a new `Competition` row (e.g., Tier 3, Group 2).
    - Trigger a "Mini-Seed": Generate 16 new CPU teams, their players, and a new double round-robin calendar for this specific competition.
    - Claim the first team for the user.

### 3. Background Seeding
To avoid slow registration, the system could pre-seed one "Empty League" (all CPU) as soon as the last one gets its 12th human manager.

## Acceptance Criteria
- [ ] Registration never fails with "League is full" as long as disk space is available.
- [ ] New competitions are correctly named and integrated into the global standings.
- [ ] Fixtures for new leagues are generated immediately.
