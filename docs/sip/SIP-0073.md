## Summary

Aggiunge `height_cm` e `weight_kg` al modello `player`. Gli attributi fisici
incidono su tre sistemi già esistenti secondo la regola di parità PHP/Go:

1. **Allenamento** (PHP) — BMI deviante dalla norma posizionale aumenta il costo
   in freschezza del carico fisico giornaliero.
2. **Match engine** (PHP + Go parità) — il Physical Fitness Index medio della
   formazione modifica il bonus di squadra che determina le probabilità di gol.
3. **Portiere** (PHP + Go parità) — altezza < 183 cm penalizza l'effettività del
   `skill_po` nei calcolatori.

---

## Formule

### BMI e Physical Fitness Index (PFI)

```
bmi = weight_kg / (height_cm / 100)²

refBmi per posizione:
  GK → 24.0
  DF → 23.5
  MF → 22.5
  FW → 22.0

bmiDeviation = |bmi - refBmi|
PFI = clamp(1.0 - bmiDeviation × 0.02, 0.92, 1.04)
```

Esempi:
| BMI delta | PFI    |
|-----------|--------|
| 0.0       | 1.04   |
| 1.0       | 1.02   |
| 2.0       | 1.00   |
| 4.0       | 0.96   |
| 6.0       | 0.92 ✂ |

### PFI squadra (match engine)

```
teamPFI = media(PFI di tutti i titolari in formazione)
homeBonus *= teamPFI          // scala il bonus esistente dei trait
awayBonus *= teamPFI
```

Parità: identica formula in `MatchEngine.php` e `engine/match.go`.

### GK height penalty

```
gkHeightPenalty = max(0, (183 - height_cm) × 0.5)   // punti sottratti da skill_po effettivo
```

Applicato solo nel calcolo del moltiplicatore portiere (non alla stat persistita).

### Training — freschezza (solo PHP)

```
if bmiDeviation > 1.5 AND playerFreshDelta < 0:
    penalty = clamp(floor(bmiDeviation × 0.4), 1, 2)
    playerFreshDelta -= penalty
```
