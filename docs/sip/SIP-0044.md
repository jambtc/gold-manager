# SIP-0044 — Special Roles: Captain, Penalty Taker, Free Kick Specialist

| Field   | Value                 |
|---------|-----------------------|
| Status  | Accepted (Implemented) ✅  |
| Author  | Gold Manager Dev Team |
| Created | 2026-05-19            |

## Summary

Allow the manager to manually assign three special roles per formation:
- **Capitano** — boosts team morale and some department totals
- **Rigorista** — used when a penalty is awarded
- **Specialista punizioni** — used for free kicks

The system also auto-suggests the best candidate based on stats/character
(restored from `gu-classic/formazione_dx.php`), but the manager can override.

---

## DB Schema

Add three nullable columns to the `formation` table:

```sql
ALTER TABLE formation
  ADD COLUMN captain_player_id   INT NULL,

  ADD COLUMN freekick_player_id  INT NULL;
```

## Auto-Suggestion Algorithm (from GU Classic `formazione_dx.php`)

If no manual assignment is set, these are computed automatically each tick.

### Captain score

```php
$captainScore = $player->general_skill * match(strtolower($player->character)) {
    'carismatico' => 25,
    'popolare'    => 10,
    'introverso'  => 1,
    default       => 5,
} + round($player->experience / 100 * 15, 1);
```

Highest score among starters → auto-captain.

### Penalty taker score

```php
$foot_bonus = match($player->foot) {
    'R'  =>  20,   // right-footed: bonus
    'L'  => -20,   // left-footed: penalty
    'LR' =>   0,   // ambidextrous: neutral
};
$penaltyScore = ($player->general_skill + $player->skill_tc * 1.3 + $player->skill_tr)
              + $foot_bonus;
// If player has 'rigori' special skill: × 2
```

Highest score among starters → auto-rigorista.

### Free kick score

```php
$fkScore = ($player->skill_tc * 1.3 + $player->skill_tr);
// If player has 'calcidipunizione' special skill: × 2
```

Highest score → auto-specialista punizioni.

## Match Engine Effect

### Captain (SIP-0037 extension)

The `carismatico` aura effect (adjacent zones +2%) is applied by default.
When a player is **explicitly designated as captain** (regardless of character):
- +1% all starters (team morale boost)
- If character is `carismatico`: stacks (+3% total)

```php
// In computeTeamTotals, after individual multipliers:
if ($captainId) {
    foreach ($starters as $p) {
        if ($p->id !== $captainId) {
            $multiplier *= 1.01; // captain morale
        }
    }
}
```

### Penalty / Free Kick

When the match engine generates a set piece event, it looks up:
1. `formation->penalty_player_id` (or auto-best if null)
2. Uses that player's `skill_tc` and `skill_tr` for the precision gate

The existing `Step 5: Gate precisione` becomes:

```php
// Base precision cap: 30%
$precisionCap = 30;

// If set piece situation (future implementation):
$taker = $this->resolveTaker($fixture, $side, 'penalty'); // or 'freekick'
if ($taker) {
    $bonus = ($taker->skill_tc * 0.2 + $taker->skill_tr * 0.3) / 10;
    $precisionCap = min(60, 30 + (int)$bonus);
}
```

## UI — Formation View Panel

In the player list (SIP-0032 layout), add badge assignment buttons:

Each player card shows three toggle buttons (dimmed if not assigned, active if assigned):

```
[🛡 C]  Captain
[⚽ R]  Rigorista
[🎯 P]  Punizioni
```

Click → immediate AJAX call → saves to formation. Only one player can hold each role.
Assigning to a new player removes it from the previous holder.

Visual indicator on the pitch: jersey shows small badge overlay (🛡, ⚽, 🎯).

## New Endpoint

```
POST /formation/set-role
{
  "formation_id": 5,
  "role": "captain|penalty|freekick",
  "player_id": 12   // null to clear
}
```

Returns `{"success": true, "player_name": "Marco Rossi"}`.

## Bench Designation (Related)

While assigning roles, the manager also sees the bench. Players NOT in formation
are on the bench by default. The bench is shown in the substitution modal (SIP-0043).

No explicit "bench assignment" needed: bench = squad − formation starters.
The manager can optionally **order the bench** (priority for substitutions), but
this is optional and deferred.
