# SIP-0027 — Season Rollover

| Field   | Value             |
|---------|-------------------|
| Status  | Accepted (Implemented) |
| Author  | Gold Manager Dev Team |
| Created | 2026-05-16        |

## Summary

Define the end-of-season process: archive results, age players, expire and
renew contracts, reset budgets and standings, then open the next season.
Season rollover is triggered automatically by `EconomyController` once all
fixtures in all competitions are `FINISHED`.

---

## Trigger Condition

```
All fixtures WHERE season = N AND status != FINISHED → none remaining
```

The console command `./yii economy/season-rollover` runs the process for
season N and advances the world to season N+1. It is also called
automatically at the end of `EconomyController::actionRunCron` when the
condition is met.

---

## Steps (in order, single DB transaction)

### 1. Archive Season Results

- Copy each `standing` row into a new `standing_archive` table that includes
  `season` and a snapshot timestamp. Schema mirrors `standing` plus
  `season INT NOT NULL`.

### 2. Player Aging

Every player gains one year of age:

```sql
UPDATE player SET age = age + 1;
```

Players aged > 38 without a contract extension are removed from the
free-agent pool (they retire). A `player_event` record
`type = 'retirement'` is inserted for historical display.

### 3. Skill Decay / Development

Applied after aging, using `PlayerValuator` logic extended with growth curves:

| Age range | Primary stats | Secondary stats |
|-----------|--------------|-----------------|
| < 23      | +rand(0,3)   | +rand(0,2)      |
| 23–27     | +rand(0,1)   | +rand(0,1)      |
| 28–30     | 0            | 0               |
| 31–34     | −rand(0,2)   | −rand(0,1)      |
| > 34      | −rand(1,4)   | −rand(0,2)      |

Stats are always clamped to [1, 99]. `general_skill` is recalculated.

### 4. Contract Expiry

Contracts where `season_end = N` (the season just finished) are set to
`status = expired`. The player's `team_id` is set to `NULL` (free agent).

Teams receive a notification: "Il contratto di {player} è scaduto."

### 5. Season Budget Allocation

Each team receives a fixed seasonal grant added to their current budget:

```
grant = base_grant + (standing_position_bonus * (N - final_position))
```

Where:
- `base_grant = 500_000` €
- `standing_position_bonus = 50_000` € per position above last

This ensures lower-ranked teams get less but still enough to survive.

### 6. Stadium Revenue Reset

```sql
UPDATE stadium SET season_revenue = 0;
```

### 7. Standing Reset

All `standing` rows for the active season are reset to zero (played, won,
drawn, lost, goals_for, goals_against, points = 0). `season` is incremented.

### 8. Fixture Generation for New Season

`FixtureSeeder::seed()` is called for each competition, generating a new
double round-robin calendar for season N+1. Match dates start 7 days after
rollover.

### 9. Competition Season Increment

```sql
UPDATE competition SET season = season + 1;
```

---

## New Table: `standing_archive`

```sql
CREATE TABLE standing_archive (
    id             INT AUTO_INCREMENT PRIMARY KEY,
    standing_id    INT NOT NULL,
    competition_id INT NOT NULL,
    team_id        INT NOT NULL,
    season         INT NOT NULL,
    final_position INT NOT NULL,
    points         INT NOT NULL DEFAULT 0,
    played         INT NOT NULL DEFAULT 0,
    won            INT NOT NULL DEFAULT 0,
    drawn          INT NOT NULL DEFAULT 0,
    lost           INT NOT NULL DEFAULT 0,
    goals_for      INT NOT NULL DEFAULT 0,
    goals_against  INT NOT NULL DEFAULT 0,
    archived_at    INT NOT NULL
);
```

## Acceptance Criteria

- [x] `./yii economy/season-rollover` runs without error on a completed season.
- [x] All standings are archived to `standing_archive` before reset.
- [x] Every player gains +1 age; retirement applied to age > 38.
- [x] Stat growth/decay applied per age-range table.
- [x] Contracts with `season_end = N` are expired; players become free agents.
- [x] Each team receives season budget allocation.
- [x] `stadium.season_revenue` reset to 0.
- [x] New fixture calendar generated for season N+1.
- [x] `competition.season` incremented.
- [x] Promotion/relegation executed before standing reset (see [[SIP-0028]]).
- [x] Running rollover on an incomplete season aborts with error.
