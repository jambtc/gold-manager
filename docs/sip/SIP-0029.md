# SIP-0029 — Admin Panel & Platform Governance

| Field   | Value                 |
|---------|-----------------------|
| Status  | Accepted (Implemented)     |
| Author  | Gold Manager Dev Team |
| Created | 2026-05-16            |

## Summary

Define the full scope of the admin panel: what the platform administrator
can see, configure, and act upon. The admin is a separate role (`role =
'admin'`) that does not manage a team. Their interface is `/admin/*`.

---

## Admin Capabilities

### 1. Platform Overview (Dashboard)

Aggregated statistics shown at a glance on `/admin/index`:

| Metric | Source |
|--------|--------|
| Totale manager registrati | `COUNT(user WHERE role = 'manager')` |
| Slot manager disponibili (CPU libere in Serie C) | `COUNT(team WHERE is_cpu=1 AND user_id IS NULL) JOIN standing → tier=3` |
| Campionati attivi | `COUNT(DISTINCT competition.id)` |
| Partite in corso | `COUNT(fixture WHERE status = PLAYING)` |
| Partite programmate | `COUNT(fixture WHERE status = SCHEDULED)` |
| Partite concluse (stagione corrente) | `COUNT(fixture WHERE status = FINISHED)` |
| Stagione corrente | `MIN(competition.season)` (tutti devono essere allineati) |
| Giornata corrente | Calcolata da fixture completate / totale giornate |
| Totale giocatori nel mondo | `COUNT(player)` |

---

### 2. League Management

Route: `/admin/leagues`

Visualizza tutti i campionati (Serie A, B, C, per girone) con:
- Numero squadre (totale / umane / CPU)
- Giornate completate / totali
- Pulsante "Simula giornata" → trigghera `game/run-fixtures` per quella competition
- Pulsante "Genera calendario" → utile se la stagione non ha ancora fixture
- Flag se il campionato è pronto per il rollover (tutte le partite FINISHED)

---

### 3. Manager Management

Route: `/admin/index` (già parzialmente implementato)

Per ogni manager:
- Username, squadra, lega, data registrazione
- **Elimina manager** → team restituito a CPU ✅ (implementato)
- **Reimposta password** → genera nuova password temporanea e la mostra all'admin
- **Promuovi ad Admin** → cambia `role = 'admin'` (con conferma)
- **Forza assegnazione squadra** → se il manager non ha squadra, gli assegna manualmente

---

### 4. Season Control

Route: `/admin/season`

- Visualizza stato corrente: stagione N, giornata X/Y, fixture rimanenti
- **Avvia rollover manuale** → esegue `economy/season-rollover` (solo se condizione met)
- **Forza rollover** → bypassa il controllo "tutte le partite finite" (emergenza)
- Storico stagioni: tabella `standing_archive` con risultati finali per stagione

---

### 5. World Statistics

Route: `/admin/stats`

| Sezione | Contenuto |
|---------|-----------|
| Top scorer assoluti | Giocatori con più gol nelle `match_event` |
| Squadre con budget più alto | Ranking per `team.budget` |
| Squadre più vincenti | Rank per `standing.points` (stagione corrente) |
| Giocatori più pagati | Rank per `contract.salary` |
| Età media per serie | Media `player.age` per tier |
| Stadio più grande | Max `stadium.capacity` |

---

### 6. System Tools

Route: `/admin/tools`

| Azione | Effetto |
|--------|---------|
| **Seed mondo** | Esegue `game/seed` se DB vuoto (utile primo avvio) |
| **Reset completo** | Elimina tutto e ri-seeda (solo in ambiente dev) |
| **Esporta log partite** | CSV di tutti i `match_event` della stagione |
| **Verifica integrità** | Controlla: team senza standing, fixture orfane, contratti duplicati |

---

## Route Map

```
GET  /admin/index          Dashboard + manager list
GET  /admin/leagues        Campionati overview
POST /admin/simulate-round Simula giornata di una competition
GET  /admin/season         Stato stagione + storico
POST /admin/run-rollover   Avvia season rollover
GET  /admin/stats          Statistiche mondo
GET  /admin/tools          Tool di sistema
POST /admin/delete-user    Elimina manager ✅ (implementato)
POST /admin/reset-password Reimposta password manager
POST /admin/promote-admin  Promuovi manager ad admin
```

---

## Access Control

Tutte le route `/admin/*` richiedono `role = 'admin'`.
Qualsiasi accesso da parte di un guest → redirect `/site/login`.
Qualsiasi accesso da parte di un manager → 403 Forbidden.

---

## UI Conventions

- Sidebar di navigazione dedicata (non la navbar manager)
- Card statistiche in cima con cifre aggregate
- Tabelle con azioni inline
- Modal di conferma per ogni azione distruttiva
- Flash messages per esito di ogni operazione

---

## Acceptance Criteria

- [ ] `/admin/index` mostra statistiche aggregate in cima alla pagina.
- [ ] Eliminazione manager: team restituito a CPU, flash di conferma. ✅
- [ ] Reset password: nuova password temporanea mostrata all'admin.
- [ ] `/admin/leagues` mostra tutti i gironi con progress giornate.
- [ ] `/admin/season` mostra stato stagione e permette rollover manuale.
- [ ] `/admin/stats` mostra almeno 4 delle metriche elencate in §5.
- [ ] Tutte le azioni distruttive hanno modal di conferma.
- [ ] Accesso negato (403) per manager e guest.
