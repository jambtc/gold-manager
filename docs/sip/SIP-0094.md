# SIP-0094 — Assistman in Telecronaca

| Campo  | Valore                 |
|--------|------------------------|
| Status | Accepted (Implemented) |
| Data   | 2026-06-03             |

## Problema

Il nome dell'assistman è salvato nel `detail` JSON dell'evento gol
(`assister_name`, `assister_id`), ma non compare nel testo di telecronaca
né nel fallback né nel prompt Ollama.

## Soluzione

- **Fallback Go/PHP**: "GOL! {scorer} su assist di {assister}! ..."
- **Prompt Ollama**: includere `assist: {assister}` nei fatti passati al modello
- **Live view**: mostrare "{scorer} ⚽ (ass. {assister})" nell'event item
- **PHP engine**: stessa logica nel fallback di `saveEvent` per il gol

## Acceptance Criteria

- [x] Telecronaca Go include il nome assistman quando disponibile
- [x] PHP engine include il nome assistman nel fallback
- [x] Prompt Ollama include assist nei fatti
- [x] Live view mostra assist nell'event item
