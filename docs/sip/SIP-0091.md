# SIP-0091 — Contract Duration & Termination Fees

| Campo    | Valore                  |
|----------|-------------------------|
| Status   | Accepted (Implemented)  |
| Autore   | Gold Manager Dev Team   |
| Data     | 2026-06-02              |
| Dipende  | SIP-0009, SIP-0035, SIP-0046, SIP-0047 |

## Problema

I contratti di staff e giocatori non hanno penali di risoluzione anticipata.
Un manager può licenziare tutto lo staff o vendere tutti i giocatori senza costi,
rendendo le scelte contrattuali prive di conseguenze economiche.

## Soluzione

Introdurre `termination_fee` (penale di rescissione) su staff e giocatori,
calcolata al momento della firma e scalata pro-rata sul tempo rimanente.

Aggiungere a entrambi la scelta esplicita della **durata contratto** al momento
dell'ingaggio: contratti più lunghi → stipendio ridotto, contratti brevi → stipendio pieno.

---

## 1. Staff

### Nuova colonna

```sql
ALTER TABLE staff ADD termination_fee INT UNSIGNED NOT NULL DEFAULT 0;
```

### Calcolo al momento dell'assunzione

```
base_fee = salary × contract_length × rand(0.25, 0.50)
```

Esempi con salary=80.000 e factor=0.35:
- 1 stagione: fee = 28.000
- 2 stagioni: fee = 56.000
- 3 stagioni: fee = 84.000

### Pro-rata al licenziamento

```
fee_dovuta = base_fee × (stagioni_rimanenti / contract_length)
```

### Sconto durata

Il manager sceglie la durata all'ingaggio (1–3 stagioni):

| Durata  | Sconto salary |
|---------|---------------|
| 1 stagione | 0% (pieno)  |
| 2 stagioni | −10%         |
| 3 stagioni | −18%         |

### UI

- **StaffMarket / Negotiate modal**: dropdown durata + preview salary scontato + fee stimata
- **Staff view (staff in rosa)**: mostra `termination_fee` pro-rata corrente
- **Fire action**: conferma con importo fee + deduct da budget

---

## 2. Giocatori

### Colonna su `contract`

```sql
ALTER TABLE contract ADD termination_fee INT UNSIGNED NOT NULL DEFAULT 0;
```

`release_clause` rimane separata (prezzo di vendita forzata pagato da un altro team).
`termination_fee` = penale pagata DAL team che rescinde anticipatamente.

### Calcolo alla firma

```
base_fee = salary × durata_stagioni × rand(0.30, 0.60)
```

### Sconto durata (trasferimenti e rinnovi)

| Durata  | Sconto salary |
|---------|---------------|
| 1 stagione | 0%          |
| 2 stagioni | −8%          |
| 3 stagioni | −15%         |
| 4 stagioni | −20%         |
| 5 stagioni | −25%         |

### Pro-rata alla risoluzione

```
fee_dovuta = base_fee × (stagioni_rimanenti / durata_originale)
```

### UI

- **Transfer sell modal**: mostra fee stimata se si rescinde il contratto prima di vendere
- **Player detail view**: mostra fee corrente pro-rata
- **Contract renew**: dropdown durata + salary scontato + fee preview

---

## 3. Regole comuni

- La fee non si applica se il contratto è **scaduto naturalmente** (`season_end <= current_season`).
- La fee non si applica ai giocatori CPU (solo team umani).
- Valore minimo fee: **5.000€** (floor per evitare fee zero su giocatori giovani).
- Se il budget è insufficiente per pagare la fee → azione bloccata con messaggio esplicito.
- La fee viene aggiunta alle `news` come evento economico.

---

## 4. Seeding iniziale

- Staff esistenti senza fee: `termination_fee = salary × 0.35` (1 stagione implicita).
- Contratti giocatori esistenti senza fee: `termination_fee = salary × durata_residua × 0.35`.
