# SIP-0047 — Player Transfer Market v2 + Generation Engine

| Field   | Value                 |
|---------|-----------------------|

## Summary

Two interconnected features:
1. **Transfer Market v2**: buy/sell/loan players with proper offer flow (not instant buy)
2. **Generation Engine**: an independent background process that maintains the pool of
   available free agents by generating new young players and retiring old ones.

Restored from `oldGM/data_giocatori_vendi.php` (`mercato` table) and league dynamics.

---

## Part A — Transfer Market v2

### Current state

The current market (`TransferController`) is instant-buy: list a player, buyer pays fee
immediately. No negotiation, no loan, no offer/counter-offer.

### New flow

```
Manager A lists player → sets asking price
Manager B makes offer → bid stored in transfer_offer table
Manager A accepts/rejects → if accepted: transfer executes
                             if rejected: Manager B can counter-offer
```

### DB Schema additions

#### `transfer_offer` table

```sql
CREATE TABLE transfer_offer (
  id           INT AUTO_INCREMENT PRIMARY KEY,
  transfer_id  INT NOT NULL,           -- references transfer(id)
  from_team_id INT NOT NULL,
  to_team_id   INT NOT NULL,
  player_id    INT NOT NULL,
  offered_fee  INT NOT NULL,
  status       ENUM('pending','accepted','rejected','withdrawn') NOT NULL DEFAULT 'pending',
  created_at   INT NOT NULL,
  expires_at   INT NOT NULL            -- offer expires in 48h (2 ticks of 1 day)
);
```

#### `transfer` table additions

```sql
ALTER TABLE transfer
  ADD COLUMN transfer_type ENUM('sale','loan','free') NOT NULL DEFAULT 'sale',
  ADD COLUMN loan_return_season INT NULL,  -- for loans: season when player returns
  ADD COLUMN asking_fee INT NULL;          -- seller's asking price
```

### Transfer Window Enforcement (SIP-0030)

Offers can only be submitted when `TransferWindowService::isOpen()` returns true.
Outside the window, the market UI shows offers disabled with countdown to next opening.

### Loan System

- Player is temporarily assigned to buying team
- `player.team_id` updated, original team stored in `transfer.from_team_id`
- At `loan_return_season` rollover: player returns automatically
- Loan fee is paid upfront; no transfer fee

## Part B — Generation Engine

### Purpose

The transfer market needs a constant supply of free agents and young players.
The `WorldSeeder` creates the initial world but nothing adds new players after that.
The Generation Engine runs weekly (via `EconomyController`) to:

1. **Generate new youth players** (age 17–21) and add them to the free agent pool
2. **Retire old players** (age 35+ with declining stats)
3. **Generate new staff candidates** (see SIP-0046)
4. **Refresh CPU team rosters** (replace retired players with new ones)

### Free Agent Pool

New table: `player_pool` (free agents available for signing)

```sql
CREATE TABLE player_pool (
  id           INT AUTO_INCREMENT PRIMARY KEY,
  player_id    INT NOT NULL,      -- references player(id)
  asking_fee   INT NOT NULL DEFAULT 0,
  salary_ask   INT NOT NULL DEFAULT 0,
  available_since INT NOT NULL,   -- timestamp
  expires_at   INT NOT NULL       -- removed from pool if unsigned after N seasons
);
```

Players in `player_pool` have `team_id = NULL`.

### Youth Generation Algorithm

Every Monday (`EconomyController::generateYouth()`):

```php
// Target: keep pool at ~50 free agents
$current = PlayerPool::count();
$target  = 50;
$toGenerate = max(0, $target - $current);

for ($i = 0; $i < $toGenerate; $i++) {
    $age      = rand(17, 21);
    $position = $this->randomPosition();
    $skill    = rand(30, 55); // young players: lower skill, growth potential
    $player   = (new PlayerSeeder())->buildPlayer(null, $position, rand(1,99),
                    WorldData::randomFirstName() . ' ' . WorldData::randomLastName());
    $player->age = $age;
    $player->general_skill = $skill;
    $player->save(false);
    
    PlayerPool::create($player->id, $this->marketValue($player) * 0.8);
}
```

### Retirement Algorithm

```php
// Run at season rollover (SIP-0027)
$oldPlayers = Player::find()
    ->where(['>=', 'age', 35])
    ->all();

foreach ($oldPlayers as $player) {
    // Probability of retirement increases with age and declining stats
    $retirementChance = ($player->age - 34) * 0.20;  // 20% at 35, 60% at 38, 100% at 39+
    
    if ($player->age >= 39 || mt_rand(1, 100) <= ($retirementChance * 100)) {
        // Retired: remove from team/pool, create retirement event
        $player->team_id = null;
        $player->save(false);
        
        // Delete from player_pool if free agent
        PlayerPool::deleteAll(['player_id' => $player->id]);
        
        // Notify manager if it's their player
        if ($player->team->user_id) {
            // Notification: "{player} si ritira dal calcio giocato."
        }
        
        $player->delete();
    }
}
```

### CPU Team Roster Maintenance

When a CPU team loses a player (retirement, transfer):

```php
// In EconomyController::maintainCpuRosters():
foreach (Team::find()->where(['is_cpu' => 1])->all() as $team) {
    $rosterSize = count($team->players);
    if ($rosterSize < 18) {
        // Pull from free agent pool or generate new player
        $freeAgent = PlayerPool::findBest($team->id, $neededPosition);
        if ($freeAgent) {
            $freeAgent->player->team_id = $team->id;
            $freeAgent->player->save(false);
            PlayerPool::deleteAll(['player_id' => $freeAgent->player_id]);
        } else {
            // Generate directly
            $this->generatePlayerForTeam($team->id);
        }
    }
}
```

### Staff Generation

New staff candidates are generated weekly for `staff_market` (see SIP-0046):

```php
// Keep 3–5 candidates per role available
foreach (['coach','assistant','gk_coach','fitness','doctor','scout'] as $role) {
    $available = StaffMarket::countByRole($role);
    if ($available < 3) {
        StaffGenerator::generate($role);
    }
}
```

Staff efficiency formula (from `staff_offerte.php`):
```php
$ability     = rand(30, 95);
$experience  = rand(5, 30);
$motivation  = rand(60, 100);
$efficiency  = round(0.9 * $ability * $motivation / 100 + $experience / 8, 1);
```

## Part C — Transfer Market UI

### `/transfer/market` (enhanced)

Three sections:

**1. Giocatori in vendita** (listed by human managers)
- Filter: position, max price, min skill, age
- For each: player card with stats, asking fee, [Fai offerta] button
- Offer modal: input amount → POST `/transfer/offer`

**2. Free agent pool** (`player_pool`)
- Players with no team: sign directly (no transfer fee, only salary contract)
- Filter: position, age, min skill
- [Firma] button → player joins team immediately

**3. Le mie offerte**
- Offers I've made (pending/accepted/rejected)
- Offers received on my listed players with [Accetta]/[Rifiuta] buttons

### Manager Listing Flow

```
Manager clicks [Vendi] on player in team/view
→ Modal: set asking price (min: release_clause or auto-estimate)
→ Player listed in market with transfer.status = 'listed'
→ Player remains in squad but is visible to others
→ Manager can delist at any time (before any accepted offer)
```
