# SIP-0005: Authentication and Authorization

- Status: Accepted (Implemented)
- Type: Security
- Created: 2026-05-14

## Abstract

Define authentication and authorization baseline for Gold Manager v2 web and API surface.

## Specification

- Session authentication for web (implemented).
- API authentication with authenticated Yii session cookie (implemented).
- Role separation Admin/Manager using existing role field and admin-only gates (implemented).
- API rate limiting per authenticated user (implemented).
- Brute-force mitigation on login (implemented).
- Security audit logging for login success/failure/throttling (implemented).
- JWT for external stateless clients (deferred to mobile API phase / SIP-0017).

## Roles

- Super Admin
- Team Manager
- Guest

## Security

- Password hashing (Yii security component)
- CSRF protection on web forms/controllers
- Brute-force mitigation (`GM_LOGIN_*` env knobs)
- API request throttling (`GM_API_RATE_*` env knobs)
- Audit logging (`security.auth` category)
