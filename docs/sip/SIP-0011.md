# SIP-0011: Match Simulation Engine

- Status: Accepted (Implemented)
- Type: Gameplay
- Created: 2026-05-14

## Abstract

Define the match simulation engine for Gold Manager v2.

## Motivation

The match engine is the core of the football manager experience. It must be deterministic enough to test, but dynamic enough to generate believable matches.

## Specification

The engine SHALL calculate match events using:

- Team strength
- Player attributes
- Tactics
- Formation
- Morale
- Fitness
- Injuries
- Home advantage
- Random variation

## Event types

- Kickoff
- Goal
- Shot
- Save
- Foul
- Yellow card
- Red card
- Injury
- Substitution
- Tactical change
- Half time
- Full time

## Determinism

Each match SHALL support an optional seed value so simulations can be reproduced during tests.

## Output

The engine SHALL produce:

- Final score
- Timeline events
- Player ratings
- Statistics
- Standing updates

## Security considerations

The client MUST NOT be trusted to calculate match results.

## Migration considerations

Legacy match logic SHALL be identified and mapped before final implementation.
