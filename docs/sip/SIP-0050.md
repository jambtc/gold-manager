# SIP-0050 — News Feed (Notiziario)

| Field   | Value                 |
|---------|-----------------------|
| Status  | Accepted (Implemented)     |
| Author  | Gold Manager Dev Team |
| Created | 2026-05-19            |

## Summary

A per-user news feed that aggregates all in-game events into a single timeline.
The manager can see: transfer activity, match results, staff changes, injuries,
invitations, financial events — all in one scrollable feed with unread count.

---

## DB Schema

```sql
CREATE TABLE news_item (
  id           INT AUTO_INCREMENT PRIMARY KEY,
  user_id      INT NOT NULL,          -- target user (NULL = broadcast to all)
  category     VARCHAR(20) NOT NULL,  -- transfer|match|staff|injury|finance|friendly|system
  icon         VARCHAR(10) NOT NULL,  -- emoji icon
  title        VARCHAR(120) NOT NULL,
  body         TEXT NULL,
  link_url     VARCHAR(255) NULL,     -- optional deep link
  is_read      TINYINT NOT NULL DEFAULT 0,
  priority     TINYINT NOT NULL DEFAULT 0,  -- 0=normal, 1=important, 2=urgent
  created_at   INT NOT NULL,
  INDEX (user_id, is_read, created_at)
);
```

## Event Categories & Examples

### Transfers
- 🔄 `{player}` ceduto a `{team}` per €{fee}
- 🛒 Acquistato `{player}` da `{team}` per €{fee}
- 📋 `{player}` svincolato, disponibile come free agent
- 📬 `{team}` ha fatto un'offerta di €{fee} per `{player}` → [Accetta] [Rifiuta]
- ✅ `{team}` ha accettato la tua offerta per `{player}`
- ❌ `{team}` ha rifiutato la tua offerta per `{player}`

### Staff
- 👔 Assunto `{name}` come `{role}` (efficienza: {eff}%)
- 👋 `{name}` ha lasciato il club (contratto scaduto)
- 📋 Offerta ricevuta per `{name}` dal `{team}` → ignore/sell

### Injuries
- 🏥 `{player}` infortunato: `{type}` — fuori `{weeks}` settimane
- 💪 `{player}` è tornato disponibile

### Discipline
- 🟨 `{player}` squalificato (3 gialli accumulati) — salta `{n}` gara/e
- 🟥 `{player}` espulso — squalificato per `{n}` gara/e

### Friendly
- 📬 Invito amichevole da `{team}` per `{date}` → [Accetta] [Rifiuta]
- ✅ `{team}` ha accettato la tua sfida amichevole
- ❌ `{team}` ha declinato la tua sfida: "`{reason}`"

### Match results
- ⚽ Vinto `{score}` contro `{team}` (Campionato)
- 🤝 Pareggiato `{score}` contro `{team}`
- ❌ Sconfitto `{score}` contro `{team}`
- 🏆 PROMOZIONE in `{serie}`!
- ⬇️ Retrocessione in `{serie}`

### Finance
- 💰 Incassato €{amount} dal match day (Stadio {name})
- 📉 Paghe settimanali: −€{amount}
- 🏟️ Stadio potenziato al livello `{n}` (+{cap} posti)

### System
- 🔔 Nuova stagione iniziata — `{season}` campionato
- ⚙️ Aggiornamento tattico applicato

## News Generation Points

News items are created by existing controllers/services:

| Event | Creator |
|-------|---------|
| Transfer accepted/rejected | `TransferController::actionBid()` |
| Offer received | `TransferController::actionListPlayer()` |
| Staff hired/fired | `StaffController::actionHire()` / `actionFire()` |
| Injury | `MatchEngine::checkInjuryRisk()` |
| Suspension | `EconomyController::checkSuspensions()` |
| Friendly invite | `FriendlyController::actionChallenge()` |
| Match result | `MatchEngine::finalizeMatch()` |
| Promotion/relegation | `EconomyController::runPromotion()` |

### Helper

```php
// NewsService::create()
NewsService::create($userId, 'transfer', '🔄', 
    "Marco Rossi ceduto a Fortis Borgo",
    "Trasferimento concluso per €180.000",
    '/transfer/history'
);
```

## UI

### Navbar Badge

```
🔔 [3]   ← unread count badge on bell icon
```

Badge disappears when `/news` is visited (mark all as read).

### `/news` Page

Full-page feed: newest first, grouped by day.

```
── Oggi ──────────────────────────────────────────
📬  Fortis Borgo ti ha sfidato a un'amichevole
    Mercoledì 22 maggio — [Accetta] [Rifiuta]
    14:23

⚽  Vinto 2-1 contro Borghetto United
    Campionato Serie C — [Vedi report]
    11:05

── Ieri ──────────────────────────────────────────
🏥  Marco Rossi infortunato: distorsione lieve
    Fuori 2 settimane — [Vedi rosa]
    23:45
...
```

Action buttons inline (Accept/Reject challenges, View match report, etc.).

### Dashboard widget

Last 3 unread items shown on the Dashboard with [Vedi tutto →] link.
