## Summary

manage the contract duration, fire. Efficiency formula and negotiation mechanics
restored from `oldGM/staff_offerte.php` and `staff_contra.php`.

## Staff Stat Model (from legacy `staff_mercato`)

Each staff member on the market has:

| Field | Legacy | Description |
|-------|--------|-------------|
| `name` | `s_descrizione` | Name |
| `role` | — | coach / assistant / gk_coach / fitness / doctor / scout |
| `ability` | `s_abi` | Raw skill 0–100 |
| `experience` | `s_esp` | Years in the profession 0–40 |
| `motivation` | `s_mot` | Current motivation 0–100 |
| `salary` | `s_sti` | Monthly wage in € |
| `contract_ends` | `s_scadenza` | Season contract expires |
| `negotiations` | `s_contrattazioni` | Remaining negotiation attempts (0–4) |

### Efficiency Formula (from `staff_offerte.php` line 55)

```php
$efficiency = round(0.9 * $ability * $motivation / 100 + $experience / 8, 1);
// Range: 0–100, used in SIP-0035 match bonus
```

## DB Schema

### New table: `staff_market`

```sql
CREATE TABLE staff_market (
  id              INT AUTO_INCREMENT PRIMARY KEY,
  name            VARCHAR(80) NOT NULL,
  role            VARCHAR(20) NOT NULL,
  ability         TINYINT NOT NULL DEFAULT 50,
  experience      TINYINT NOT NULL DEFAULT 10,
  motivation      TINYINT NOT NULL DEFAULT 80,
  salary          INT NOT NULL DEFAULT 50000,
  contract_length TINYINT NOT NULL DEFAULT 2,  -- seasons
  negotiations    TINYINT NOT NULL DEFAULT 4,  -- attempts remaining
  generated_at    INT NOT NULL,
  expires_at      INT NOT NULL  -- removed from market if unsigned by season end
);
```

### Extend `staff` table

```sql
ALTER TABLE staff
  ADD COLUMN ability       TINYINT NOT NULL DEFAULT 50,
  ADD COLUMN experience    TINYINT NOT NULL DEFAULT 10,
  ADD COLUMN motivation    TINYINT NOT NULL DEFAULT 80,
  ADD COLUMN contract_ends INT NOT NULL DEFAULT 1,  -- season number
  ADD COLUMN age           TINYINT NOT NULL DEFAULT 35;
```

`efficiency` (existing column, SIP-0035) is recomputed from `ability × motivation / experience`.

## Negotiation Mechanic (from `staff_contra.php`)

Each attempt has a probability of success based on remaining attempts:

| Attempts remaining | Success probability |
|-------------------|-------------------|
| 4 | 90% |
| 3 | 80% |
| 2 | 70% |
| 1 | 60% |
| 0 | 0% (locked out) |

On success: contract signed, staff moved from `staff_market` to `staff`.
On failure: `negotiations--`. At 0: candidate removed from the team's market list.

The manager can also **offer a higher salary** to reset negotiations to 4 (once per candidate).

## UI — Staff Panel (`/staff`)

### Tab 1: Staff corrente

Table of hired staff with: name, role, efficiency, salary, contract_ends, [Fire] button.
"Fire" costs one week salary (compensation).

### Tab 2: Mercato Staff

Shows candidates generated for the season (from `staff_market`).

For each candidate:
- Name, role, efficiency preview (blurred until first negotiation)
- Salary request
- Negotiations remaining: `●●●●` (4 full) / `●●●○` (3) / etc.

Action: [Contratta] button — attempts negotiation at current probability.

### Tab 3: Storico

History of past staff (fired or contract expired): name, role, seasons served.

## Firing

```
POST /staff/fire
{ "staff_id": 5 }
```

- Removes from `staff` table
- Deducts 1 week salary from team budget (compensation)
- If team has no coach after firing: match engine uses default (no bonus)

## Contract Expiry

`EconomyController::seasonRollover()` (SIP-0027):
- Staff with `contract_ends <= current_season` → fired automatically
- Notification shown: "Contratto scaduto: {name} lascia il club."
- Staff motivation drops if not renewed in last season: `motivation -= 10`

## Salary Market Rate

Staff salary is set by `StaffGenerator` (see SIP-0047) based on role × ability:

```php
$baseSalary = [
    'coach'      => 80_000,  // per season
    'assistant'  => 40_000,
    'gk_coach'   => 45_000,
    'fitness'    => 30_000,
    'doctor'     => 35_000,
    'scout'      => 25_000,
];
$salary = (int)($baseSalary[$role] * $ability / 50); // scales with ability
```
