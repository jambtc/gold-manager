# SIP-0079 — Multilingual Match Commentary

| Campo    | Valore                          |
|----------|---------------------------------|
| ID       | SIP-0079                        |
| Stato    | Accepted (Implemented)          |
| Priorità | Medium                          |
| Dipende  | SIP-0069 (i18n), SIP-0075 (skill_cp) |

## Problema

La cronaca delle partite (live + replay) è completamente hardcoded in italiano:

1. **Prompt LLM** — Go `strictOllamaPrompt()` / `longOllamaPrompt()` e PHP `LlmCommentary::strictPrompt()` istruiscono esplicitamente il modello: *"Scrivi telecronaca calcio italiana"*
2. **Fallback strings** — Go e PHP hanno fallback hardcoded in italiano ("GOOOOOL!", "Triplice fischio!", ecc.)
3. **Template DB** — `commentary_template` table contiene testi italiani
4. **Weather/field** — Go `randomWeatherField()` restituisce stringhe italiane ("soleggiato", "terreno pesante e scivoloso")
5. **Modello Ollama** — `telecronista` ha la persona italiana baked-in nel Modelfile; risponde in italiano anche se il prompt cambia lingua

---

## Architettura proposta

### Principio
La lingua della cronaca segue la lingua del **manager che possiede la squadra di casa** (`fixture.home_team_id → team.user_id → user.language`). Per partite CPU vs CPU, default `it-IT`.

### Step 1 — Lingua fixture in DB

Aggiungere colonna `language VARCHAR(10) NOT NULL DEFAULT 'it-IT'` alla tabella `fixture`.  
Migration reale: `m260529_210000_add_language_to_fixture.php`.

Popolata al momento della creazione fixture da `SchedulerService` / `FriendlyController`:
```php
$fixture->language = $homeManager?->language ?? 'it-IT';
```

### Step 2 — Prompt LLM multilingua (PHP)

`LlmCommentary::strictPrompt()` diventa:
```php
private static function strictPrompt(string $facts, string $lang = 'it-IT'): string
{
    $langInstruction = match ($lang) {
        'en-US' => "Write football commentary in English.",
        default  => "Scrivi telecronaca calcio italiana.",
    };
    return "{$langInstruction}\n"
        . "Rules:\n- one sentence;\n- max 22 words;\n- use only supplied data;\n"
        . "- no invented names, actions or context;\n- no preamble, no quotes.\n"
        . "Data: {$facts}";
}
```

`generate()` accetta `string $lang` e lo passa a `strictPrompt()`.  
Tutti i metodi pubblici (`getPreMatch`, `getTickComment`, ecc.) accettano `string $lang`.

### Step 3 — Prompt LLM multilingua (Go)

`strictOllamaPrompt(facts, lang string)` e `longOllamaPrompt(facts, lang string)`:
```go
func strictOllamaPrompt(facts, lang string) string {
    instruction := "Scrivi telecronaca calcio italiana."
    if lang == "en-US" {
        instruction = "Write football commentary in English."
    }
    return instruction + "\nRules:\n- one sentence;\n- max 22 words;\n" +
        "- use only supplied data;\n- no invented names or context;\n- no quotes.\nData: " + facts
}
```

Il Go engine legge la lingua della fixture dal DB prima di generare la cronaca:
```go
var fixtureLang string
e.DB.Get(&fixtureLang, "SELECT COALESCE(language,'it-IT') FROM fixture WHERE id=?", fixtureID)
```

### Step 4 — Fallback strings

**PHP** `LlmCommentary`: i fallback diventano un array per lingua:
```php
private static function fallbacks(string $type, string $lang, ...): string
{
    return match ($lang) {
        'en-US' => match ($type) {
            'goal'       => "GOOOAAL! {$attTeam} scores at minute {$minute}! {$hs}-{$as}!",
            'gk_save'    => "What a save! {$defTeam}'s goalkeeper stops {$attTeam}!",
            'near_miss'  => "So close! {$attTeam} hits the post!",
            'half_time'  => "Half time! Score: {$homeScore}-{$awayScore}.",
            'full_time'  => "Full time! {$home} {$homeScore}-{$awayScore} {$away}!",
            default      => "{$attTeam} press forward.",
        },
        default => match ($type) {   // it-IT (current strings)
            'goal'       => "GOOOOOL! {$attTeam} segna al minuto {$minute}! {$hs}-{$as}!",
            // ... (current strings)
        },
    };
}
```

**Go**: stessa struttura con `switch lang`.

### Step 5 — Template DB

Aggiungere colonna `language VARCHAR(10) NOT NULL DEFAULT 'it-IT'` alla tabella `commentary_template`.  
`CommentaryTemplateService::pick()` aggiunge `AND language = :lang` alla query.  
Le righe esistenti restano `it-IT`; nuove righe `en-US` da inserire via seed migration.

### Step 6 — Weather/field multilingua (Go)

`randomWeatherField()` accetta `lang`:
```go
func randomWeatherField(lang string) (string, string) {
    if lang == "en-US" {
        options := []struct{ weather, field string }{
            {"sunny",   "dry and fast pitch"},
            {"cloudy",  "regular compact surface"},
            {"windy",   "gusty wind, long balls trickier"},
            {"rainy",   "heavy and slippery pitch"},
        }
        // ...
    }
    // current Italian options
}
```

- Lingue diverse da `it-IT` ed `en-US` — aggiungibili in seguito come nuovi `case`
