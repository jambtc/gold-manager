## Obiettivo

Avviare un nodo Hyperledger Besu IBFT 2.0 privato come servizio Docker,
integrato nella stack Gold Manager.

## Architettura

```
docker-compose.yml
  ├── php          (app)
  ├── go-worker    (match engine)
  ├── mysql
  ├── ollama
  └── besu         ← nuovo
```

Un singolo nodo è sufficiente per la fase iniziale (nessun consensus distribuito).
In produzione si potrà espandere a 4 validatori IBFT 2.0.

## docker-compose service

```yaml
besu:
  image: hyperledger/besu:latest
  volumes:
    - ./blockchain/besu-data:/opt/besu/data
    - ./blockchain/genesis.json:/opt/besu/genesis.json:ro
    - ./blockchain/config.toml:/opt/besu/config.toml:ro
  ports:
    - "8545:8545"   # JSON-RPC HTTP
    - "8546:8546"   # WebSocket
  command: >
    --genesis-file=/opt/besu/genesis.json
    --config-file=/opt/besu/config.toml
    --data-path=/opt/besu/data
    --rpc-http-enabled
    --rpc-http-api=ETH,NET,WEB3,IBFT
    --host-allowlist="*"
    --rpc-http-cors-origins="*"
  healthcheck:
    test: ["CMD", "curl", "-f", "http://localhost:8545"]
    interval: 10s
    retries: 5
```

## config.toml

```toml
data-path="/opt/besu/data"
genesis-file="/opt/besu/genesis.json"
rpc-http-enabled=true
rpc-http-api=["ETH","NET","WEB3","IBFT"]
```

## Env var Docker Compose

```env
BESU_ENABLED=0     # 0 = nodo non avviato (default); 1 = avvia container
```

## Init script

`blockchain/scripts/init-besu.sh`:
1. Genera account server wallet (`besu --genesis-file ... account new`).
2. Inserisce indirizzo in `genesis.json`.
3. Avvia il nodo.
4. Attende healthcheck.
5. Deploya `GoldManagerCoin` + `GameEconomy` (vedi SIP-0084).
6. Scrive indirizzi contratti in `.env`.

## Acceptance Criteria

- [ ] `docker-compose up besu` avvia il nodo senza errori.
- [ ] `curl http://localhost:8545` risponde con JSON-RPC.
- [ ] `eth_chainId` restituisce `0x539` (1337 decimal).
- [ ] `BESU_ENABLED=0` esclude il servizio dalla stack senza rompere gli altri container.
- [ ] Init script completa deploy contratti e popola `.env` automaticamente.
